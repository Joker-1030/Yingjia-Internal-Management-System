# DEC-235 省份迁移按地市分别选择接收 PM

## 当前决定

1. 编辑区域移出省份并选择目标区域后，已有 PM 负责的地市必须逐个选择目标区域内在职 PM。
2. 同一省份的不同地市可以交给不同 PM；每个地市按“原 PM + 目标 PM”形成独立交接分组和责任变更记录。
3. 无 PM 负责的地市不进入交接选择；没有已分配地市的省份只选择目标区域。
4. 省份映射与全部地市交接、客户、关键人、未完成任务、适用项目和普通未落选商机迁移继续整体生效；任一目标 PM 失效、映射并发变化或业务迁移失败，全部保持原值。

## 边界

- 目标区域仍按移出省份逐个选择；目标 PM 候选仅来自对应目标区域内在职 PM。
- 不改变市场副总完全复用区域总监权限、admin 全局维护权限或普通 PM 交接权限。
- 平台师资合作商机继续保持生态独立责任，不随地区责任迁移。
