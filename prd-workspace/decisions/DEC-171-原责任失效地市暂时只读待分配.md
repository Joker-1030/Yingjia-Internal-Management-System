# DEC-171：原责任失效地市暂时只读待分配

- 日期：2026-08-25
- 状态：已确认
- 背景：UI-CONFIG-IMPL-004 已能通过有效 PM 与责任生效事实识别原责任失效，但修复候选将该类地市加入初次分配，可能覆盖原 PM、原生效时间并把审计错误记录为“未分配”。当前产品尚未定义责任恢复或重新分配流程。
- 决策：
  1. 原责任失效后，地市当前继续显示“待分配”；有客户时使用黄色行底色，并按既有规则触发“有客户的地市缺少有效 PM”区域配置异常。
  2. 原责任失效地市暂时只读，操作列显示“—”；对所有角色均不提供分配、直接调整、交接、查看范围或其他操作入口。
  3. 原责任失效地市不得进入批量分配候选，提交层不得用初次分配覆盖其原 PM、原生效时间或责任历史。
  4. 从未分配的待分配地市不受此限制，继续按现有权限和流程执行分配。
  5. 后续责任恢复或重新分配能力必须另行形成 Product Owner 决策；在此之前不得从代码、历史流程或实现便利推导处理方式。
- 替代关系：本决策补充 DEC-170 对“原责任失效”与“从未分配”的操作边界；DEC-169/170 的状态、黄色警示、异常原因和责任历史判断继续有效。
- 未采用方案：把原责任失效当作初次分配；自动使用直接调整；新增未确认的责任恢复流程。
- 原因：暂时只读可以保留异常可见性和历史证据，同时避免在处理流程未确认时覆盖责任事实或产生错误审计。
- 决策人：Product Owner（2026-08-25 明确确认“原责任失效后暂时只展示待分配而不提供操作”，随后回复“执行”）
- 影响范围：M08 Current PRD、Acceptance、Prototype 地市责任操作列与分配候选/提交保护
