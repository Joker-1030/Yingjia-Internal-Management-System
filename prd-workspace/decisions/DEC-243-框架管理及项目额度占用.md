# DEC-243 框架管理及项目额度占用

状态：CURRENT / 已确认、NOT REVIEWED；2026-11-06；Approved Baseline NONE；NEW/CHANGE，Impact HIGH；POST-REVIEW CHANGE / NOT SYNCABLE。

## 当前规则

1. M11新增客户专属框架及框架管理菜单，五项必填为名称、客户公司、总金额、有效起止日期；admin新增和编辑，其他经营角色按确认范围只读。编辑客户锁定，名称/金额/起止可改；金额不低于最新已占用（含冻结），有效期覆盖全部关联项目的最早开始至最晚结束（含取消/中止），等于允许。保存复核权限和最新集合，失败原值保持；框架身份/项目自身金额日期、商业快照和阶段不回写，当前框架识别使用最新信息。不引入框架删除。新增默认启用；admin可在未到期时启停；到期当天有效、次日优先成为不可逆已到期，只读且不能编辑任何字段或启用恢复。新项目/切入只允许启用；原关联项目继续沿原阶段/日期/额度规则执行及编辑，状态不改项目、额度或历史；提交复核最新状态，禁止旧页面绕过。
2. 普通培训/软件项目均可选框架服务，必须选同客户框架且全执行区间有效；仅直接服务、总金额手填，结账金额等于项目金额，天数不决定金额。生态平台师资合作分支不得选框架。
3. 立项即冻结；交付转交付使用，已完成不重复；已使用含冻结，待使用=总额-交付使用-冻结。取消全释放；中止无结算全释放、有结算按应结算额占用。额度变更按项目稳定身份一次计算，更新超过总额拒绝并整体保持原项目/额度；编辑排除自身旧额，释放/新增与保存同次。
4. 框架培训主讲必选，各槽按类型/状态/员工资格/整日期排期，不按采购包课程；非框架方向与软件人员规则不变。
