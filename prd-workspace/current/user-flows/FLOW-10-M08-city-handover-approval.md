- 当前定位：Current Product Flow；文件名为历史兼容标识。原负责 PM 从“地市管理”发起普通交接，提交企微审批，通过后按计划生效；总监直接调整无需审批（DEC-143/DEC-173/DEC-259）

```mermaid
flowchart TD
    A[原负责 PM 从地市管理发起交接<br/>DEC-143:唯一可发起角色] --> B[选择目标PM、1-50个本人负责地市、计划日和原因]
    B --> C{权限、目标资格、影响和版本校验}
    C -- 不通过 --> H[阻止提交,原 PM 继续负责]
    C -- 通过 --> D[用户确认]
    D --> P[提交企业微信审批<br/>原PM继续负责]
    P --> Q{企微同步结果}
    Q -- 驳回或撤回 --> H
    Q -- 通过 --> I{计划生效日是否已到?}
    I -- 否 --> J[待生效<br/>原 PM 继续负责]
    J --> I
    I -- 是或到期 --> E[重新校验当前负责人和目标资格]
    E --> G[一次性迁移:客户负责人/关键人责任/<br/>未完成任务/覆盖KPI待办/数据范围/适用项目]
    G --> K{迁移写入失败?}
    K -- 是 --> L[记录M08生效失败<br/>保留原责任,可对原记录幂等重试]
    K -- 否 --> M[已生效,通知原PM/新PM/区域总监]
    N[区域总监/admin 需即时换人<br/>→ 直接调整,不走交接]
```

平台不提供同意、驳回、撤回或目标PM接收；审批和撤回沿企微模板同步。区域总监在主管范围内直接调整，二次确认后立即生效，无需审批。
