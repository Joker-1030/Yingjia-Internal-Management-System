## DEC-127：区域配置权限调整——市场副总可编辑省份，区域总监本区域可见并可分配

- 日期：2026-08-19
- 状态：由 DEC-135、DEC-138、DEC-139、DEC-143、DEC-144 补充或部分替代（市场副总可同时编辑驻地；区域主管可空且可一人多区域；地市责任操作统一为分配/直接调整；交接仅原 PM 发起）
- 背景：原设计仅 admin 可维护区域关联省份和地市责任，市场副总作为全国市场负责人对省份归属只能走管理员通道；区域总监对本人区域的地市分配也只能依赖 admin 或交接审批，效率低。
- 决策：市场副总获得“编辑区域配置”权限，但仅能修改关联省份（驻地等其余字段仍仅 admin），保存执行与 admin 相同的影响预览、校验和审计。区域总监在 M08 仅可见本人主管的区域中心（其他区域在列表、筛选、数量、详情和直接访问中完全不可见），并可在本区域内执行地市“初次分配”和“直接调整”，支持按地市选 PM 和按 PM 分配地市两个方向入口。总裁、市场副总对地市责任仍只读，交接审批路由不变。
- 未采用方案：区域总监可编辑区域省份；市场副总可分配地市责任。
- 原因：省份归属属全国市场规划职责；地市分配属区域日常管理职责；各授权给对应角色并保留数据隔离。
- 决策人：产品经理（2026-08-19 评审意见第 10、11 项）
- 影响范围：F003、F004、角色数据范围、功能操作矩阵、AC-F003-16/21/24/25、AC-F004-05
