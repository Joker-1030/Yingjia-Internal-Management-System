# DEC-223：成交金额考核与商机过程观察

- 日期：2026-10-12；状态：已确认，CURRENT；Product Review：NOT REVIEWED。
- 依据：Product Owner明确“现阶段KPI主要是成交金额，目前没有考核商机数量，中选金额就是成交金额，商机是过程性观察指标”，并确认“沿用现有分配机制，改为成交金额目标”。本轮已授权PRD及Demo调整，替代数量目标方案。

## 当前决定

1. 市场销售指标改为成交金额目标；中选金额就是成交金额，以中选日期汇总完成。数量、预估金额、阶段和类型仅作过程观察，取消数量目标考核。复用中选金额位置，不新增合同对象、财务收入、回款或已签约状态。
2. 沿用公司→运营中心→PM的月度分配、年度/季度汇总、权限层级、上下级守恒、当前月/未来月调整、二次确认与版本留痕。金额含税人民币元最多2位小数；原数量目标不自动转换为金额。
3. 工作台周期主要指标为成交目标、成交金额、差额、完成率；总裁原区域快照替换为区域完成目标对比，独立时间/运营中心筛选。当前推进中和周期新建/中选数量作为观察信息。其他角色目标完成同步成交金额口径，原权限与当前快照边界保持。
4. 完整产品行为由 `prd-workspace/current/modules/M12-sales-opportunity.md` → §6.1/6.2、§7.1/7.1.1/7.1.2及 `prd-workspace/current/modules/M01-dashboard.md` → §4.10拥有；验收AC-M12-50/51/52、AC-F014-51。

## 替代与保留

替代DEC-194中仅维护商机数量目标的限制，以及DEC-222和2026-10-12总裁指标表达中的数量目标考核/区域快照部分。合同、回款、开票、成本、毛利排除及商机六阶段、数据权限、原日期事件统计继续有效；后来落选不冲销既有中选事件。历史数量目标与旧Decision证据不改写。
