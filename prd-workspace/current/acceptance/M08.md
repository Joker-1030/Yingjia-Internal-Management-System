# M08 Acceptance Criteria

> Stable IDs, priority, and row order are preserved. Product-owner-confirmed wording replacements are governed below and retain their prior wording as Historical / Replaced Evidence.

| AC 编号 | Given | When | Then | 优先级 |
| --- | --- | --- | --- | --- |
| AC-F003-11 | 某省已归属区域 A | admin 尝试加入区域 B | 前端禁选，伪造请求仍返回冲突并指出区域 A，不写入任何关系 | P0 |
| AC-F003-12 | 区域驻地城市不属于该区域任一关联省份 | admin 或市场副总编辑关联省份并保存 | 驻地保持原值且允许保存；驻地从标准城市中独立选择，关联省份变化不清空或限制驻地 | P1 |
| AC-F003-13 | HR/人事将正常部门标记为区域中心并选择任一在职非内置员工为主管 | admin 打开 M08 | M06 自动补齐主管的部门成员关系和缺失的区域总监角色；新区域使用同一部门 ID、名称、编码和主管出现并为待配置，不存在第二个区域或总监编辑字段 | P0 |
| AC-F003-14 | 待移除省份仍有关联客户或地市责任 | 保存区域 | 系统展示影响并阻止移除，不能产生无区域客户 | P0 |
| AC-F003-15 | 用户打开区域配置详情并调整到桌面、中等和移动宽度 | 查看菜单、标题及五项摘要 | 名称均为“区域中心与地市配置”；五项摘要按 5 列、3+2、2/1 列稳定排布，无悬空分隔线、重叠或横向溢出 | P1 |
| AC-F003-16 | 总裁、市场副总、区域总监或 PM 登录 | 查看有权区域并分别尝试修改省份、驻地或执行地市分配 | 总裁只读；市场副总可编辑关联省份和驻地；区域总监仅见本人主管区域并可执行分配/直接调整；PM 只读；越权伪造写请求返回 403，admin 可执行全部区域写操作 | P0 |
| AC-F003-17 | admin 查看区域详情 | 尝试修改区域名称、编码或区域总监 | 页面字段只读且提示到 M06 维护；接口不提供第二写入口，组织数据不变 | P0 |
| AC-F003-18 | HR/人事在 M06 更换区域中心主管 | 查看 M08、省公司当前责任和既有任务/审批 | 新主管自动取得成员关系及缺失的区域总监角色，M08 只读同步新主管；旧主管不再主管任何区域中心时只移除系统自动角色，既有任务和审批处理人不因员工角色变化自动改派 | P0 |
| AC-F003-19 | HR 或 admin 编辑区域中心主管的人工系统角色 | 保存并查看角色来源 | 区域总监角色由当前主管关系自动确保，不因人工角色达到 5 个而阻断或重复；解除全部区域中心主管关系时只移除系统自动来源角色，人工原有区域总监角色保留 | P0 |
| AC-F003-20 | admin 保存区域省份映射时任一业务责任更新失败 | 查看区域、客户和工作台 | 全部写入回滚，原省份归属和范围继续有效，不产生双区域或无区域客户 | P0 |
| AC-F003-21 | HR、admin、总裁、市场副总和区域总监分别操作组织与区域页面 | 尝试创建部门、设置区域主管和修改省份/驻地/地市映射 | HR/admin 在 M06 维护组织、主管及员工多部门关系；admin 在 M08 维护省份、驻地与地市映射；市场副总只维护关联省份和驻地；区域总监按本人主管区域分配/直接调整地市责任；总裁两处均只读，M08 不获得员工编辑入口 | P0 |
| AC-F003-22 | 已配置区域因员工停用、迁移或同步异常出现主管失效、必填配置失效或客户地市无有效 PM | 打开区域列表或详情，随后修复全部条件 | 员工停用时其区域/地市当前责任由 M08 清空；页面显示“配置异常”、当前具体异常原因、影响和处理入口，不自动改派或扩大范围；修复后 5 分钟内恢复已配置并留下异常起止记录 | P0 |

> Source Governance（2026-08-24，DEC-165）：AC-F003-13/18/19/21/22 先前要求主管预先属于部门、预先具备区域总监角色、角色移除统一阻断或自动迁移既有待办的措辞均为 Historical / Replaced Evidence。当前 M06 自动维护主管成员关系与带来源的区域总监角色；M08 继续唯一拥有区域/地市责任，并在员工停用时清空当前责任而不接管员工生命周期。
>
> Source Governance（2026-08-24，DEC-167）：AC-F003-12/22/25 的驻地省份联动、无异常原因展示和内联映射影响预览旧措辞为 Historical / Replaced Evidence。当前驻地城市与关联省份独立；配置异常必须展示具体原因；区域编辑不展示内联影响预览字段，但省份唯一性、业务引用阻断、二次确认和原子保存继续有效。
| AC-F003-23 | 同一区域发生配置异常，其中一个正常客户无法解析负责人、另一个仍可按有效责任解析 | 查看区域、客户经营、任务和告警，随后修复区域配置 | 区域显示配置异常；只有无法解析负责人的客户进入客户责任配置异常并暂停无法分配的新任务，另一客户责任和业务不变；修复后 5 分钟内逐客重算并仅恢复符合条件的客户 | P0 |
| AC-F003-24 | 存在多个区域中心，区域总监仅主管其中一个 | 打开 M08 列表和省份筛选，并伪造其他区域的详情、编辑和分配接口 | 仅本人主管区域可见可操作；其他区域在列表、筛选、计数和直接访问中不存在，直接访问返回 403 且不返回区域名称；本人区域内分配和直接调整可用 | P0 |
| AC-F003-25 | 市场副总打开任一区域配置 | 先后编辑该区域关联省份与驻地城市并保存 | 编辑弹窗不展示映射影响预览、新增省份、移除省份或移除影响字段；省份冲突和业务引用阻断仍校验，保存仍需二次确认；驻地可不属于关联省份；审计记录市场副总身份，区域中心名称/编码/区域总监仍只读；总裁执行同样操作全部只读 | P0 |
| AC-F004-05 | 多个省份下均有未分配负责人城市 | admin 或本区域区域总监先多选省份，再从联动结果多选 1-50 个城市并分配给一个区域内 PM | 表单无单选/多选切换；省份变化实时刷新未分配城市并清除失效选择；一次生效并形成已通过流程记录，每个城市只有该 PM 一条当前有效责任；区域总监越权城市被拒绝 | P0 |
| AC-F004-06 | 原 PM 发起本人负责城市交接 | 区域中心主管审批通过 | 无目标 PM 接收节点；生效前原 PM 继续负责，通过且到日期后客户、关键人、未完成任务、覆盖 KPI、当前审批和权限同事务迁移 | P0 |
| AC-F004-07 | 区域中心主管或系统管理员尝试发起地市交接 | 查看按钮并伪造请求 | 页面无发起入口，接口返回 403（DEC-143）；区域总监仅可通过直接调整更换负责人 | P0 |
| AC-F004-08 | 交接申请读取后负责人已被另一流程改变 | 原申请继续审批 | 返回状态冲突并要求刷新，不基于旧负责人重复迁移 | P0 |
| AC-F004-09 | admin 或本区域区域总监对已有负责人地市执行直接调整 | 查看影响摘要并二次确认且业务迁移成功 | 立即切换负责人，形成已通过流程记录且不生成审批节点；目标 PM 收到包含地市和待办数量的消息，历史责任不改写 | P0 |
| AC-F004-10 | 目标 PM 已停用、调出区域中心、账号停用或失去 PM 角色 | PM、区域总监或 admin 提交/生效交接 | 候选不出现，伪造或过期申请被阻止；原负责人和全部业务对象保持不变 | P0 |
| AC-F004-11 | 总裁或市场副总尝试分配、直接调整或发起地市交接 | 查看按钮并伪造请求 | 页面无对应入口且接口返回 403；市场副总编辑区域省份/驻地的权限不扩大为地市责任操作权限 | P0 |
| AC-F004-12 | 区域总监或 admin 在地市负责人配置中查看 PM 的负责客户 | 依次打开负责人详情、负责客户列表和客户单位详情 | 下钻最深到客户单位详情，可查看档案与责任信息；客户单位详情无进入关键人详情的入口，页面提供返回客户经营的提示入口 | P0 |
