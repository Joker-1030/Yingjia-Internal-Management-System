# DEC-189：M07 权限直接生效并仅保留只读变更日志

- 日期：2026-08-31
- 状态：已确认
- 背景：一期需要可控地修改角色权限并追溯发生过什么，不需要建设历史权限恢复能力。
- 决策：系统管理员选择或编辑权限后查看影响并确认，新配置直接生效。系统保留只读、只追加的权限变更日志，记录前后权限、原因、影响、操作者、时间和结果。当前版本不提供一键回滚、选择历史版本恢复、双版本并存或权限变更审批。
- 替代关系：替代 DEC-085 中“通过回滚保证变更可追溯”及权限回滚的当前表达；admin 独占、固定内置角色、四层权限、依赖校验、影响预览、新请求立即按新权限鉴权和完整审计继续有效。
- Future Planning：一键回滚本期不做；未来是否提供须另行确认。
- 未改变：权限变更失败的原子性、并发保护、影响确认、权限依赖校验和只读审计。
- 决策人：Product Owner
- 影响范围：M07、Acceptance、Shared、Glossary、Product Boundary
