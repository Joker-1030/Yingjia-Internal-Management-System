## DEC-082：版本主 Demo 必须继承上一版完整应用

- 日期：2026-08-14
- 状态：已确认
- 背景：V2.0 销售板块独立 Demo 与 V1.1.0 完整 Demo 在应用壳、设计样式、账号权限、主数据和可复用交互上出现差异。产品版本迭代需要表达完整升级结果，而不是用新的独立 HTML 替换上一版本产品。
- 决策：同一产品的新版本必须以上一版当前合并主 Demo 的副本为底稿，默认继承应用壳、设计变量、导航、登录账号、角色权限、数据范围、共享主数据、抽屉、弹窗、表格、消息和审批底座。允许制作单功能板块 Demo 用于快速验证，但必须标记为 module sandbox，不能成为当前版本主 Demo。版本交付前必须生成一个包含上一版能力和本版新增能力的合并主 Demo；`HANDOFF.md` 只能将合并版标为当前主 Demo，并记录旧功能回归结果。
- 未采用方案：每个新增模块单独重做一套页面并作为版本主 Demo；只追求视觉近似而复制平行账号、权限或主数据；覆盖已发布旧版 Demo。
- 原因：连续演进能保证跨模块数据、角色立场、审批和通用交互一致，也使旧功能回归与最终合并成为可验证交付物。
- 决策人：产品经理
- 影响范围：CHG-126、TC-200、V2.0 合并主 Demo、后续所有版本 Demo 交付
