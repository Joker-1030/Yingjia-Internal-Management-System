## DEC-085：权限授权菜单与功能由系统管理员独占

- 日期：2026-08-17
- 状态：部分 Historical / Replaced；F002 admin 独占、固定管理员模板、版本与审计继续有效，“本人信息展示数据范围摘要”被 DEC-091 移除，当前本人信息只展示系统角色名称且不返回范围计算来源
- 背景：既有基线和 V1.2.0 初稿允许总裁查看或维护角色模板，与“权限授权属于平台安全管理能力”的最新产品边界冲突，也可能向业务角色泄露其他角色的权限结构和影响人数。
- 决策：“权限授权”是 F002 唯一权限管理入口，本期仅唯一内置系统管理员账号 `admin` 可见菜单、访问页面与直接路由、读取角色模板及权限数据、维护非管理员内置角色模板、查看权限版本和审计记录。鉴权使用不可变系统账号 ID 和内置管理员身份，不以可变登录名字符串作为唯一依据；F002 不进入非管理员可编辑权限树，其他账号不能通过岗位兼任、权限并集或员工例外获得。总裁、市场副总、区域总监、PM 及后续其他账号均无该菜单、页面和接口权限，越权请求统一返回 403 且不返回角色模板、权限树、权限数量或影响人数。所有员工可在“本人信息”只读查看本人角色名称和数据范围摘要，但不因此获得 F002。系统管理员模板固定全权限，不可降权、停用或删除；数据范围类型和计算来源只读；继续禁止员工级例外授权。每次模板变更必须填写原因、预览影响、生成不可覆盖的新权限版本并完整审计，新请求立即按新版本鉴权。
- 未采用方案：总裁与系统管理员共同维护；总裁只读查看权限树；仅隐藏非管理员菜单但允许直接路由或查询接口；允许对员工单独追加例外权限。
- 原因：将高风险授权能力收敛至唯一技术管理角色，避免权限泄露和多头配置，同时通过版本、影响预览、回滚和真实身份审计保证变更可追溯。
- 决策人：产品经理
- 影响范围：F002、CHG-130、CHG-132、AC-F002-08、AC-F002-10、AC-F002-13 至 AC-F002-27、正式产品与全部 Demo
