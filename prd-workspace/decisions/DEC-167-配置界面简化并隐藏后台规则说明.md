## DEC-167：配置界面简化并隐藏后台规则说明

- 日期：2026-08-24
- 状态：已确认
- 背景：Product Owner 反馈区域配置、客户基础配置和组织员工页面存在字段联动限制、内联影响预览、内部版本字段及自动/人工来源说明，增加理解成本；同时配置异常只显示状态而没有显示可处理原因。
- 决策：
  1. M08 的驻地城市从标准城市中独立选择，不要求属于区域关联省份；关联省份变化不清空驻地。
  2. M08 编辑区域弹窗删除“映射影响预览”“新增省份”“移除省份”“移除影响”等内联字段。省份唯一性、业务引用阻断、保存二次确认、原子保存和审计继续有效。
  3. M08 出现“配置异常”时必须同时展示当前具体异常原因、影响和处理入口，不得只显示异常状态标签。
  4. M09 生日/节假日站内提醒节点改为固定复选框：截止日及提前 1/2/3/5/7/10/15/30 天；候选展示方式后续被 DEC-168 替代，至少选择一项且不允许自由输入的规则继续有效。
  5. M09 职级与常规维系周期页面不向任何角色展示配置版本字段。内部版本递增、乐观锁、审计、任务生成规则快照和历史追溯继续有效。本项部分替代 DEC-150 的“admin 可见”展示规则，不删除内部版本能力。
  6. M06 员工列表、详情、编辑表单和角色账号记录不在角色名称后标注“自动/人工/区域中心主管自动”等来源，也不展示自动角色由后台维护、不占人工上限等实现说明；角色来源、自动维护、人工角色 1-5 上限、权限并集和审计继续有效。员工主管标签统一为“主管”，不显示“本部门主管”。
  7. 当前业务 UI 立即按 Shared 03 扫描并移除同类内部系统规则说明，但保留完成操作所需的约束、权限、后果、二次确认、异常原因、验证错误、安全警告、业务状态和恢复指导。
- 未采用方案：驻地继续受关联省份限制；保留区域弹窗的内联影响预览；仅 admin 查看配置版本；只删除 M06 当前发现的来源后缀而不处理其他页面同类说明；机械删除所有帮助或说明文案。
- 原因：让界面集中表达用户需要选择、确认和处理的业务信息，避免把后台实现机制当成操作说明，同时不牺牲校验、并发、审计、异常处理或业务安全。
- 决策人：Product Owner（2026-08-24 明确确认 `1A / 2A / 3A / 4B`）
- 影响范围：M06、M08、M09、Shared 03、相关 Acceptance、当前 Prototype UI/Copy
