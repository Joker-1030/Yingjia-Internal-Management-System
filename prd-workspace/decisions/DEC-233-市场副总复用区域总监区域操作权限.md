# DEC-233 市场副总复用区域总监区域操作权限

## 当前决定

1. 市场副总复用区域总监在 M08 的全部区域/地市业务操作权限，并覆盖公司全部区域。
2. 市场副总可编辑区域省份/驻地、分配未负责地市、直接调整已有地市负责人；其全国市场数据范围保持不变。
3. 市场副总不发起普通 PM 地市交接，不取得 admin 专属故障处理、组织维护或总裁以外的特殊权限。

## 边界

- 不新增角色，不改变 M06 组织事实、区域中心主管关系或 M07 角色模板的固定范围类型。
- 区域总监仍仅可操作本人主管区域；市场副总的全部区域范围来自其全国市场数据范围。
- 省份迁移时的地市交接另由后续区域配置变更规则定义。

## 依据

- Product Owner request: “市场副总拥有区域总监的所有权限，静总要对某一区域内进行操作，现在操作不了”。
