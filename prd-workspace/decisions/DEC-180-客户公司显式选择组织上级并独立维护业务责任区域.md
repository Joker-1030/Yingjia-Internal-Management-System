# DEC-180：客户公司显式选择组织上级并独立维护业务责任区域

- 日期：2026-08-28
- 状态：已确认
- 决策人：Product Owner

## 决策

集团公司继续直接隶属行业且不形成集团嵌套。每个客户公司必须由系统管理员显式选择一个上级，上级只能是所属集团或同集团内正常客户公司；禁止跨集团、选择自身或后代。显式上级稳定 ID 是客户组织树位置的唯一依据，不再根据省、市、区县或公司层级自动计算、补挂或重组父级。

删除独立“公司层级”和公司所在地省/市/区县字段。客户公司只维护独立的业务责任层级及对应业务责任省/市/区县；它们不参与组织树归属，只用于解析区域中心、客户负责人、数据权限、任务执行人、项目负责人和按业务责任区域浏览/筛选。

系统管理员可调整客户公司的显式上级；调整只改变当前组织路径，不改变客户稳定 ID、业务责任、关键人/任务/项目引用或历史快照，并记录前后上级、操作人和时间。正常下级公司存在时，上级集团或客户公司不能直接停用，必须先迁移或处理下级。

存量公司以 DEC-157 下原自动归属结果回填显式上级稳定 ID，原责任层级和责任省/市/区县迁移为业务责任事实，不新增所在地数据。

## 替代关系

- 完全替代 DEC-157 的按责任省市区自动形成公司子树、补建中间公司后自动重组和独立公司层级字段。
- 不恢复 DEC-153 的集团架构类型。
- 不恢复 DEC-156 的区划继承或集团模式分支。
- DEC-161 的客户部门唯一归属客户公司、岗位唯一归属部门继续有效。
