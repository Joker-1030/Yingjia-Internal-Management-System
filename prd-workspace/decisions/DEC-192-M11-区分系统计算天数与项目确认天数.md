# DEC-192：M11 区分系统计算天数与项目确认天数

- 日期：2026-09-01
- 状态：已确认
- 背景：现有`项目天数`同时承担日期计算结果和用户最终确认值，手工调整后无法区分系统计算事实与培训项目实际计费依据；M10 初始化项目导入也需要明确输入值和系统计算值的归属。
- 决策：M11 将现有`项目天数`拆分为只读`系统计算天数`和可编辑`项目确认天数`。系统计算天数根据开始/结束时间按既有自然日规则自动计算；项目确认天数默认同步，用户手工修改后日期变化只更新系统计算天数。培训项目费用按项目确认天数计算，AI 软件项目确认天数只记录周期、不参与项目金额计算。创建、开始前编辑和进行中修改结束时间时，两值不一致必须通过标题为`确认使用不同的项目天数`的弹窗二次确认；正文分两行显示`系统计算天数：X天；`和`项目确认天数：Y天；`，按钮为`返回修改 / 确认保存`。项目详情展示两项天数，项目列表只展示项目确认天数。M10 项目模板将原项目天数映射为项目确认天数，系统计算天数按开始/结束时间自动计算并写入。
- 替代关系：替代 M11 中单一`项目天数`自动计算后可直接手工覆盖的表达，并补充 DEC-177 的初始化项目导入字段映射；不改变自然日计算算法。
- 未改变：项目类型、项目阶段、项目编号、权限、平台公司规则、M10 批次状态、单行原子和部分成功规则。
- 决策人：Product Owner
- 影响范围：M10、M11、Acceptance、User Flow、Revision History
