# DEC-239 总裁与市场副总完整老师管理权限

## 当前决定

1. 总裁、市场副总均获得与admin相同的M13“老师管理”“老师排期”能力，范围为全部内部老师、外部机构及个人渠道老师；不以教学管理人员分配范围限制两者。
2. 复用原老师建档、编辑、启用/停用、人工不可用新增/编辑/删除；查看全部公共资料、完整联系方式（仍默认脱敏、主动查看）、渠道及课酬；简历查看/预览/下载/上传/删除。仍执行原字段、版本、附件及排期冲突校验，不能覆盖项目占用。
3. 两角色均可为全部教学管理人员配置既有内部老师、外部机构渠道、外部个人渠道三项范围，不仅限师资管理部。原师资管理部主管只能配置本部门管理人员的边界保持。
4. 复用现有角色及四层权限节点，可按M07模板收紧页面、操作、字段及附件；收紧或角色失效后旧页面/直接请求重新鉴权。兼任老师不缩小有效管理角色范围；原经营工作台默认入口保持。
5. 本次仅开放M13，不授予系统管理员身份、M07权限授权、M06员工/账号/角色维护或M11项目编辑权；项目占用和选师等业务不变量保持，排期日程点击仍只读，人工不可用从原老师详情维护。权限历史不回填。
