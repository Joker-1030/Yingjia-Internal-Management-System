# DEC-231 商机列表按账号未读更新优先

## 当前决定

1. 总裁、市场副总和区域总监查看商机列表时，按账号分别记录每个商机的最近查看详情时间。
2. 商机 `updatedAt` 晚于该账号最近查看详情时间，或该账号尚无该商机已读记录时，视为“有更新未读”。未读商机整体优先于已读商机；两组内继续沿用最近更新时间倒序、同时间商机编号倒序。
3. 未读商机名称左侧显示提醒圆点。用户进入该商机详情后，立即将该商机标记为当前账号已读并在返回列表时消除圆点；其他账号的状态不受影响。商机再次发生会更新 `updatedAt`，对应账号重新显示未读圆点。
4. PM、生态合作员及其他角色继续沿用原商机列表，不显示该未读圆点，也不启用未读优先排序。

## 边界

- 已读事实属于账号与商机的查看状态，不修改商机业务对象、最近更新时间、阶段、跟进、支撑或历史。
- 筛选、分页、详情权限和原更新时间触发规则保持；排序在当前筛选结果内生效。
- 本 Demo 使用当前会话内按账号的已读时间映射表达该规则，不新增独立消息对象。
