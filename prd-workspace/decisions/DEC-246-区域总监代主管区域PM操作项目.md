# DEC-246 区域总监代主管区域 PM 操作项目

状态：CURRENT / 已确认、NOT REVIEWED；日期2026-11-10；Approved Baseline UNKNOWN；CHANGE / HIGH；POST-REVIEW CHANGE，普通同步资格NOT SYNCABLE。

## 当前规则

1. 区域总监可对本人当前主管中心内 PM 负责的非平台师资合作项目，执行 PM 原有全部阶段操作：编辑、确认 AI 软件项目交付、资料上传/删除、满意度及其附件维护、取消与中止。包括指定 PM 的省级及市级/区县级项目，不限是否由该总监创建。
2. 使用原客户唯一责任中心与总监当前主管中心并集，地理与行业中心同规则；不按项目客户的物理地址、PM任职部门或旧创建资格扩大。不获得跨中心或生态项目操作权，兼任财务的公司读取不扩大总监写范围。
3. 沿用原项目阶段、原操作/附件权限、日期、金额/框架额度、老师/排期及原因校验；已完成仅追加原资料，不能删除或替换；已取消/已中止只读。列表/详情入口、直接访问、保存、二次确认和异步资料实际写入前都核验当前主管关系、角色/账号、对象及权限。M07模板只能收紧，不新增代操作授权节点。
4. PM继续为项目负责人，创建负责人快照、责任历史及本人待办归属保持；实际总监写入原操作记录的操作者、时间、前后值及适用原因，不产生责任转移。原阶段编辑可改的业务事实仍可按原规则修改，不因代操作重写其他快照。PM原操作能力保持。
5. 复用“全部项目”和既有详情/表单/确认框，不新增代办页面、审批、接收、通知或指标。不把可代操作的PM项目加入总监“我的项目”或复制PM执行待办。其他模块客户/维系/商机的总监执行范围保持。

## 确认上下文与替代范围
