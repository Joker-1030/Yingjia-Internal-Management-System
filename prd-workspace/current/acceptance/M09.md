# M09 Acceptance Criteria

> Existing stable IDs, priority, and row order are preserved. Product-owner-confirmed wording replacements and the appended AC-F005-40/41 are governed below.

| AC 编号 | Given | When | Then | 优先级 |
| --- | --- | --- | --- | --- |
| AC-F005-12 | 用户配置周期 30 天 | 输入重复提醒节点、31 天节点或超过 10 个节点 | 非法值就地提示且不能保存；合法节点去重后倒序保存 | P0 |
| AC-F005-13 | 部门原子仍被任职或覆盖 KPI 引用 | admin 发起停用 | 系统汇总所有公司关系下的有效引用并阻止停用；不提供批量替代或改写任职，必须先逐人完成调岗或结束引用 | P0 |
| AC-F005-14 | 行业已被集团引用 | 停用行业后打开新增集团和存量详情 | 新建候选不含该行业，存量详情仍正确展示且引用不丢失 | P0 |
| AC-F005-15 | 关键人生日为 02-29 | 生日规则在闰年和非闰年运行 | 闰年按 02-29 生成；非闰年按规则事件日 02-28 生成并记录折算标识，不丢失关键人 | P0 |
| AC-F005-16 | 当前年度节假日同步首次失败、持续失败及重试，分别有最近成功版本或无可用版本；随后手动或自动实际恢复后再次失败 | 查看任务调度与告警，重复处理同一故障，并处理新一轮失败 | 有最近成功版本则继续使用且不重复任务，无可用版本按原规则暂停相关调度；同一故障首次仅向 admin 告警一次，持续失败和重试不重复，其他角色不接收。手动或自动实际同步恢复后再失败才重新告警；仅使用旧版本降级不算恢复，是否发送恢复消息不影响本轮故障结束 | P0 |
| AC-F005-17 | 用户保存启用的节假日规则 | 未选择关联节假日，或所选节假日与另一启用规则在同一职级重叠 | 系统分别提示必选或列出冲突规则并阻止保存；未选择节假日不生成任务 | P0 |
| AC-F005-18 | 用户修改某职级周期并确认 | 弹窗确认后仅该职级更新，已存在任务截止不变 | 保存后新生成的任务按新周期计算；内部配置版本递增并继续用于并发、审计和任务快照，页面不展示版本字段 | P0 |
| AC-F005-19 | 用户在不同职级分别修改周期 | 每行独立保存确认 | 各职级互不影响；确认弹窗明确提示已存在任务不受影响 | P1 |
| AC-F005-20 | 岗位原子仍被当前关键人任职或进行中覆盖 KPI 引用 | 尝试停用并伪造替代岗位参数 | 系统汇总所有部门关系下的引用明细并阻止停用，忽略并拒绝替代参数；必须先逐人完成调岗或结束引用，不能批量改写任职或 KPI | P0 |
| AC-F005-21 | 两个部门需要复用同一岗位 | admin 在岗位页签关联多个部门 | 同一岗位原子使用一个稳定 ID、编码、名称、排序和状态；关联多个部门不复制岗位，不允许新建同名岗位 | P0 |
| AC-F005-22 | 用户查看四个职级的常规维系规则并生成新任务 | 检查页面字段、任务快照并伪造逾期补完成期限参数 | 页面不存在常规补完成期限字段，任务固定允许逾期补完成且补完成截止为空；伪造期限参数被拒绝且不写入规则或任务 | P0 |
| AC-F005-23 | 用户打开任一预置生日/节假日规则 | 尝试新增规则、寻找“允许逾期补完成”开关或伪造开启参数 | 页面无新增按钮且服务端拒绝创建请求；规则表单不存在允许逾期补完成和补完成期限字段，任务越过截止直接进入已过期未完成；伪造参数被拒绝且不写入规则或任务 | P0 |
| AC-F005-24 | 节假日日历同一事件先后同步两个版本并改变事件日 | 在任务生成前和生成后分别同步 | 生成前使用最新正常版本；生成后保留既有任务日期和版本快照并产生差异提示，不重复任务或静默改截止；缺少必填日历字段时整条事件不可供规则选择 | P0 |
| AC-F005-25 | 配置版本字段不对业务页面展示 | admin、总裁与市场副总分别查看职级周期配置 | 所有角色均看不到配置版本字段；内部版本、并发校验、审计和任务规则快照保持有效（DEC-167 部分替代 DEC-150） | P1 |
| AC-F005-26 | 已存在覆盖一级和二级的启用生日规则 | 编辑另一预置规则，把适用职级改为二级和三级并启用 | 系统列出冲突规则和重复职级“二级”并阻止保存；调整为仅三级后可保存，同一关键人同年只生成一条生日任务 | P0 |
| AC-F005-27 | 用户打开预置生日/节假日规则并生成任务 | 查看规则表单与生成任务的截止时间 | 规则表单不含截止宽限天数字段；单条开始为创建时间，生日截止固定为生日当天23:59:59、节假日为法定假期末日23:59:59；提前生成以事件日为基准，截止提醒按保存的截止计算；伪造宽限参数被服务端拒绝 | P1 |
| AC-F005-28 | admin、总裁、市场副总、区域总监、PM、HR 分别访问客户基础配置 | 查看七个页签并尝试维护行业、集团、客户公司、部门和岗位 | admin 可维护全部页签及关系；总裁和市场副总只能查看，区域总监、PM 和 HR 无菜单且直接访问返回 403；部门和岗位无别称字段 | P0 |
| AC-F005-29 | admin 或只读角色打开“集团”和“客户公司”页签，且同一集团含多级显式客户公司 | 分别查看集团列表与客户公司页签，并尝试使用新增入口及组织树操作 | “集团”页签只展示集团编号、名称、所属行业、统一社会信用代码、状态等集团信息，页签内仅提供“新增集团”；“客户公司”页签仅提供“新增客户公司”，左侧按“行业→集团→显式公司子树”定位公司，公司工作区按当前公司的部门关系路径和岗位关系展示，同一原子在不同公司/部门下使用各自关系上下文，不生成虚拟占位节点；树内部门只能调整上级部门和排序，岗位只能调整所属部门，不得新增部门/岗位、编辑部门或岗位基础字段、停用/恢复部门或岗位，基础字段与生命周期操作分别回到“部门”“岗位”页签 | P0 |
| AC-F005-30 | 公司导航或当前公司的部门岗位树存在超过 50 个直接子节点，且公司导航深层节点命中一个或多个已填写筛选字段 | 在公司导航执行筛选、重置和加载更多，再切换公司并浏览部门岗位树 | 公司导航不同已填写字段按 AND 取交集、筛选不受已加载页限制并保留完整祖先路径；部门岗位树不显示筛选、查询或重置，按当前公司直接浏览并保留加载更多；切换公司清空上一公司的部门岗位选中项、展开和加载状态；分页不重复、不遗漏 | P1 |
| AC-F005-31 | admin 打开部门或岗位页签 | 新增原子对象，或发起“关联到客户公司/关联到部门” | 原子表单不要求绑定单一公司/部门；关联操作可一次选择多个目标，部门关系逐目标配置上级、排序和路径，岗位关系复用同一岗位原子属性 | P0 |
| AC-F005-32 | 已有同名行业或编号服务短暂失败 | admin 新增行业并重试同一请求 | 同名按去空格、大小写不敏感规则阻止；成功时只生成一个 `IND`+6 位流水编码，失败时不落库、不重复占号 | P0 |
| AC-F005-33 | 已存在正常行业、同名集团或已使用的统一社会信用代码 | admin 新增集团并提交重复名称或信用代码 | 集团名称全局唯一，信用代码在全部集团和客户公司中全局唯一；表单和接口均不存在集团架构类型字段 | P0 |
| AC-F005-34 | 同一集团存在集团节点、多级正常客户公司和待维护客户公司 | admin 新增或调整客户公司的组织上级，并尝试选择所属集团、同集团正常公司、其他集团公司、自身或后代 | 选择所属集团或同集团正常公司时按该显式上级稳定 ID 形成当前路径；跨集团、自身、后代和成环均被阻止；调整只改变当前组织路径并记录前后上级、操作人和时间，不改变公司稳定 ID、业务责任、业务引用或历史快照 | P0 |
| AC-F005-35 | admin 新增客户公司，未选择业务责任层级后分别选择省级、市级和区县级 | 查看并填写业务责任省市区，再提交缺失、越级、停用或无法唯一解析负责人的责任区划 | 省市区始终可见；未选层级时全部禁用，省级只启用省，市级启用省/市，区县级全部启用；层级降低时清空并禁用不适用下级字段且不提交；合法责任唯一解析区域和负责人但不改变组织上级，非法责任阻止创建且原数据不变；表单和接口均不存在独立公司层级或公司所在地省市区字段 | P0 |
| AC-F005-36 | admin 在部门页签新增原子部门并发起关联 | 选择多个不同集团的客户公司并逐公司设置上级、排序和路径 | 部门名称全局唯一；同一部门可跨集团复用；每个公司关系单独保存上下文，不产生集团直属部门 | P0 |
| AC-F005-37 | 同一部门关联多个客户公司 | admin 分别调整关系上级、排序或路径 | 各公司关系可有不同上级、排序和路径；不能把一个公司的关系字段写入另一个公司，环和跨公司上级被阻止 | P0 |
| AC-F005-38 | admin 新增标准岗位并关联多个部门 | 保存岗位原子并选择多个部门 | 岗位名称全局唯一并生成全局唯一 `POS` 编码；一次关联多个部门；不允许岗位直接挂公司、别称或按部门复制岗位 | P0 |
| AC-F005-39 | 总裁、市场副总或 admin 查看行业、集团、客户公司、部门或岗位详情 | 依次打开详情或公司折叠组织工作区 | 行业/集团/公司详情只显示主数据、路径、状态和允许操作；集团不显示审计信息且没有“查看变更记录”入口；公司工作区按关系展示部门和岗位，不显示业务统计或下钻；版本冲突仍返回 409 | P0 |
| AC-F005-54 | admin 在关联弹窗中批量新增、更新或解除部门、岗位关系 | 使用单个输入框模糊搜索并多选多个客户公司或部门，其中部分目标重复、失效、关系字段非法，或已有关联申请解除 | 候选按公司名称/集团名称或部门名称/编码/说明模糊匹配；有效新增/更新目标立即保存；解除部门关系前当前公司下该部门无有效关键人，解除岗位关系前该岗位与部门关系无有效关键人；不满足解除条件的目标逐项提示原因；成功项不回滚；重复关系提示“已存在”且不重复创建；成功解除只删除关系及展示投影，不删除全局原子；失败项可重新配置后重试 | P0 |
| AC-F005-55 | 用户查看行业、集团、客户公司、部门、岗位列表或关联弹窗 | 分别填写多个拆解筛选项并提交 | 每个筛选项只匹配自身字段，多个已填写条件取交集；不存在聚合关键词搜索 | P1 |
| AC-F005-40 | admin 编辑生日或节假日规则并已设置提前生成天数 | 查看、修改站内提醒节点，并降低提前生成天数 | 始终展示全部固定复选框候选“截止日、提前 1/2/3/5/7/10/15/30 天”；超过当前提前生成天数的选项置灰且不可勾选，已选但新超出范围的节点取消选择；至少勾选 1 个有效节点，不能输入其他数值 | P0 |
| AC-F005-41 | admin 打开新增集团表单并分别提交合法数据、失败数据和重复请求 | 查看编号字段、创建结果、集团详情与集团编号筛选，并在停用或恢复后再次查看 | 新增时集团编号显示“保存后自动生成”且不可编辑；成功创建返回系统内唯一的 `CG` + 8 位数字并可按完整或部分编号独立筛选；失败不成立集团对象且不显示成功编号；重复请求返回原对象和原编号；停用、恢复或后续状态变化不修改或回收已成功分配的编号 | P0 |
| AC-F005-42 | admin 新增或编辑客户部门 | 分别留空、输入 500 字和输入超过 500 字的部门说明并查看详情 | 留空和 500 字可保存，超过 500 字阻止保存并保留输入；详情有值时显示原文，空值固定显示“未填写” | P1 |
| AC-F005-43 | admin 与任一非 admin 角色分别在 M09“客户组织树”和 M02 客户经营查看集团公司、客户公司或客户部门 | 查找停用/恢复入口并尝试直接请求 | 集团公司、客户公司和客户部门只在 M09 向 admin 提供操作入口；M02 不展示集团公司或客户公司的平行按钮。admin 可查看影响、二次确认并直接停用/恢复，成功后 M09 刷新正常/已停用状态并保留对象历史；其他角色无入口且请求返回 403、不泄露对象信息；不创建 M04 审批实例或 M05 独立记录；以客户公司为操作对象成功停用/恢复后，通知该公司客户负责人及所属区域总监，省级客户的客户负责人为所属区域总监，市级/区县级客户的客户负责人为对应地市 PM，同一员工重复命中只收一条；仅表达公司、结果与生效时间，不向总裁/市场副总广播，不展示后台处理，失败不发成功消息，访问权限保持；单独停用公司时每位接收人仅一条公司结果消息，同次联动停用多个关键人不另发逐人通知，后续独立操作关键人仍按自身规则通知 | P0 |
| AC-F005-44 | admin 分别停用一个行业、一个无有效任职或进行中覆盖 KPI 引用的标准关键人岗位和一条已启用生日/节假日规则，并另行尝试停用仍有有效引用的标准岗位 | 完成各对象既有校验、确认或保存，检查 M09 对象结果并尝试访问 M04/M05 入口 | 合法操作在 M09 直接生效且不创建 M04 审批实例、节点、流程编号、待办、抄送或回调链路；M04/M05 均无可用入口。被既有引用规则阻断的标准岗位保持原状态。规则启停只改变配置状态，不建立 M05 停用记录；非 admin 仍无写入口 | P0 |
| AC-F005-45 | admin 对集团停用/恢复，分别实际成功或失败，相关公司存在共同客户负责人或区域总监 | 查看集团结果消息及同次级联消息，并随后独立操作公司或关键人 | 成功后通知相关公司客户负责人及涉及区域总监；客户负责人按省级区域总监、市级/区县级地市 PM 映射，同一员工通过多个客户或角色重复命中时仅收一条集团结果消息，同次级联不另发公司或关键人通知；仅说明集团、结果和生效时间，不向总裁/市场副总广播，不展示后台处理，不扩大访问权；失败不发成功消息；恢复集团不自动恢复下级，后续独立操作按自身规则通知 | P0 |
| AC-F005-46 | admin 停用或恢复客户部门，分别实际成功、失败或联动影响多个关键人、任职及任务 | 查看消息及后续恢复结果 | 成功后通知该公司客户负责人及所属区域总监；客户负责人按省级区域总监、市级/区县级地市 PM 映射，同一员工重复命中时仅收一条部门结果消息；内容仅为客户公司、客户部门、结果和生效时间，不向总裁/市场副总广播，不展示后台处理，不扩大访问权；停用联动影响不逐项发送消息，失败不发成功消息；恢复不自动恢复下级对象或已关闭任务 | P0 |
| AC-F005-47 | admin 分别停用无有效任职或进行中覆盖 KPI 引用的标准关键人岗位、尝试停用仍有引用的岗位，并恢复已停用岗位 | 查看当前页面反馈与消息中心 | 合法停用/恢复只在 M09 当前页面向操作 admin 显示结果，不生成站内消息；存在引用时保持原状态并显示阻断结果，同样不生成站内消息；恢复仅重新开放为后续候选，不改变历史引用或产生业务角色通知 | P0 |
