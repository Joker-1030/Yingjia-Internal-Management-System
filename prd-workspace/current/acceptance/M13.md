# M13 培训老师管理验收

产品源：[`M13 培训老师管理`](../modules/M13-teacher-management.md)；Product Review：NOT REVIEWED。

| AC | Given / When | Then | 优先级 |
| --- | --- | --- | --- |
| AC-M13-01 | admin/有权教学管理人员建立老师档案 | 内部关联已有老师角色员工，外部不建账号；姓名、类型、手机号、至少一门采购包内课程作为教学方向必填，外部至少一个渠道、机构名必填；失败保留输入且不建立半成品 | P1 |
| AC-M13-02 | 同一外部老师有多个机构且有个人渠道 | 一份档案统一排期，每机构独立联系人、可选电话/微信/邮箱及参考课酬，个人渠道独立参考课酬；不建机构模块 | P1 |
| AC-M13-03 | admin或师资管理部主管分配教学管理范围/管理者访问双渠道老师 | admin可为全部教学管理人员配置；师资管理部主管仅可为师资管理部内教学管理人员配置；范围三项可多选；主管本人可维护全部三类老师，公共资料/排期共同维护，渠道及课酬按有权渠道，未命中范围不返回档案；其他非admin主管不能改分工 | P1 |
| AC-M13-04 | 查看/编辑老师及机构联系人联系方式 | 加密保存、默认脱敏；admin/有权管理者可看完整，内部本人只看本人完整值，项目用户始终脱敏；不改变M06手机号规则 | P1 |
| AC-M13-05 | 项目用户/老师本人请求简历预览或下载 | 不能访问；仅admin/有权教学管理人员可访问和维护，文件地址及附件接口复核同一父对象范围；不新增公开副本 | P1 |
| AC-M13-06 | 维护简历附件 | 沿用Shared通用类型/容量/数量/扫描及访问规则；不继承M11大文件或全类型内容预览；失败保留其他输入 | P1 |
| AC-M13-07 | 选择培训项目人员/保存 | 主/辅讲的教学方向包含项目所选采购包内课程，助教只校验空闲；老师启用且全部日期可用，排除自身项目占用；候选及保存双校验，任何角色不能覆盖 | P1 |
| AC-M13-08 | 同一天不同时段或跨多个自然日安排同一老师 | 首尾均按北京时间整天占用，主/辅/助教和合作渠道之间也冲突；不按确认计费天数缩减占用 | P1 |
| AC-M13-09 | 登记人工不可用与项目重叠 | 阻止并提示冲突项目，先调整项目；内部老师仅能改删本人登记项，不能改管理者或项目占用 | P1 |
| AC-M13-10 | 停用有已立项/进行中授课项目的老师 | 阻止，先换老师；已交付待资料/评价不阻断，历史保持；停用退出候选，恢复后重新匹配，不物理删除 | P1 |
| AC-M13-11 | 维护出生日期、课酬 | 年龄计算周岁；内部标准、外部各渠道参考课酬独立，元/天并选含税/不含税，未填非零；项目报价与结算不变 | P1 |
| AC-M13-12 | 查看/维护老师教学方向及采购包，创建/编辑两类培训项目 | 老师原教学方向多选候选直接来自采购包课程并显示采购包及课程；M13无独立方向目录/维护入口，采购包编辑无新增教学方向配置；项目先选有效采购包再单选包内课程，不可提交其他包的课或独立目录值；主辅讲按包内课程匹配，平台单价仍取合作课酬、普通采购包课程仍取课程报价；既有快照和历史不按名称猜测迁移或重写评价 | P1 |
| AC-M13-13 | 老师在已立项/进行中项目担任主讲或辅讲，admin或有权管理者编辑其方向 | 移除项目所用方向则阻止整个保存，提示受影响项目，原档案保持；先由项目负责人按原阶段权限更换老师或调整项目再保存，无强制覆盖；仅任助教不要求方向，已交付等历史不改写 | P1 |
| AC-M13-14 | 内部员工停用或老师角色移除，老师档案仍启用且已有授课项目；随后从新页面/旧表单新选或替换老师 | 立即退出新选/替换候选，提交复核员工在职及有效老师角色，失效者不能新增安排；已有项目、排期和历史保留，由负责人另行调整、不自动改派；员工停用时账号按M06原规则立即失效，不以换师为前置；仅撤老师角色不因此停用整个账号，也不自动变更老师档案状态 | P1 |
| AC-M13-15 | 内部老师查看排期，包含跨多天/跨月项目与人工不可用 | 只展示本人日历，默认北京时间本月、可切月份；当前月份内重叠的授课占用和人工不可用按整天连续展示，不因开始日在上月而遗漏；不提供其他老师筛选或单独老师角色的甘特图 | P1 |
| AC-M13-16 | 教学管理人员进入排期，选择一名/多名负责老师、切换月份并切日历/甘特图 | 默认日历、当前月及全部负责老师；候选和安排只在原管理范围内，甘特图老师为行/日期为列；两视图共用月份/老师筛选，切换不重置条件且数据一致，无范围/无老师不泄露其他安排 | P1 |
| AC-M13-17 | 点击日历/甘特图安排，尝试拖拽改期或进入无权项目详情 | 日程只读查看既有安排及起止日期，无拖拽改期/人员修改；项目详情沿M11原权限，不能越权直达；人工不可用维护仍按原本人自登记/有权管理范围及冲突校验，隐私/简历/课酬及占用释放规则不因视图改变 | P1 |
| AC-M13-18 | 有M13原查看权限的账号分别进入“老师管理”“老师排期”菜单 | 前者展示有权老师档案列表及既有操作，后者独立展示原日历/甘特图；不在档案列表页混排排期视图；原有档案及本人/管理排期身份沿原权限，总裁仅排期资格按AC-M13-19，无权角色不能直达；老师身份的档案菜单及页名为“我的信息”，admin/教学管理人员仍称“老师管理”；老师身份的排期菜单及页名为“我的排期”，纯老师默认进入该页；admin/教学管理人员仍称“老师排期”，兼任沿有效角色及原落地优先规则；本人档案及详情人工不可用入口、排期只读保持 | P1 |
| AC-M13-19 | 总裁进入老师排期、筛选/切换视图、尝试越权及撤销查看权限 | 仅提供“老师排期”菜单，默认当前月、全部内部/外部老师及日历，可单多选/切月/切甘特图并保留条件；共用原安排数据和只读详情，不新增档案、完整或脱敏联系方式、简历、渠道、课酬、不可用维护或启停权限；既有项目访问按M11不变；兼任仅在原其他身份范围内具备档案/维护权，排期为全体且称老师排期，总裁默认工作台保持；页面或查看操作收紧后不得从旧页面/直接调用返回排期数据 | P1 |
| AC-M13-20 | 当前师资管理部主管进入老师管理/老师排期并打开教学管理范围 | 可访问全部三类老师档案、公共资料、渠道、课酬、简历和排期，支持建档、编辑、启停、人工不可用维护及日历/甘特图；“教学管理范围”仅展示师资管理部内教学管理人员，可为其配置内部老师、外部机构渠道、外部个人渠道三项且可多选；不新增角色，其他部门主管和普通HR不能通过主管关系获得该权限 | P1 |
