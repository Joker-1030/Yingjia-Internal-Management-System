# DEC-236 责任交接迁移全部项目阶段

## 当前决定

1. 员工停用、普通 PM 地市交接、区域责任交接和直接调整时，项目不再按主阶段排除终态；`已立项`、`进行中`、`已交付`、`已完成`、`已取消`和`已中止`六个阶段的项目，均随对应 PM 地市或区域中心责任迁移到已选接收人。
2. 生态合作员停用或移除生态合作员角色时，平台师资合作项目同样按上述六个阶段全部交给另一名有效生态合作员；项目与同组未落选平台师资合作商机仍按同一交接组处理。
3. 迁移只改变当前项目负责人及责任历史；项目阶段、终态、资料、并行待办、金额/结算快照、创建负责人快照和完整历史均保持。已取消、已中止项目仍保持只读和不可恢复等终态限制。
4. 员工恢复不取回已经交出的项目负责人关系；责任组交接失败项保留原业务事实，由有权管理者继续处理，已成功组不回滚。

## 边界

- 本决定统一适用于员工停用、生态合作员角色移除、普通 PM 地市交接、区域责任交接和直接调整。
- 所有上述责任交接均迁移六个项目阶段；普通责任交接失败时仍整体阻断，员工停用的成功/失败责任组例外边界保持。
- 项目不新增独立接收人、交接状态、审批或迁移模块。
