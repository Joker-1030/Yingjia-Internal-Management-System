# DEC-245 财务角色全项目只读与项目看板

状态：CURRENT / 已确认、NOT REVIEWED；2026-11-10；Approved Baseline UNKNOWN；NEW/CHANGE，Impact HIGH；POST-REVIEW CHANGE / NOT SYNCABLE；工程NOT STARTED。

## 当前规则

1. 新增固定内置角色“财务”（FINANCE）。HR/人事或admin在原员工新增/编辑中人工分配，纳入原1-5角色上限及权限并集，不依赖财务部门名称，不另建账号或角色分配流程。M07模板可收紧，不可扩张固定业务上限。
2. 业务菜单仅工作台、项目列表/详情；系统固定登录、退出、本人信息/密码与本人消息基础能力保持。财务可只读查看公司全部六阶段项目，包括平台师资合作项目、项目资料附件的查看/在线预览/下载及变更与责任历史；列表、搜索、计数、详情、附件和直接访问同范围。原固定隐私上限保持，项目可读不授权独立客户、商机、老师敏感档案或配置页面。
3. 无项目创建/编辑、交付、资料上传/删除、评价、取消/中止等维护能力；不开放框架管理、采购包管理、平台公司管理或其他业务菜单。旧页面、旧模板及伪造请求不能授予，直接写请求拒绝。财务不是负责人，不产生执行待办。兼任其他角色时，另一角色的操作资格与对象范围同时校验；公司读取不扩大该角色的写范围。
4. 纯财务登录默认进入工作台，仅展示原“项目概况”，复用现有项目阶段/类型/资源分析、联动筛选及数量/项目金额/结账金额指标和原空值/失败口径，不展示关键人、维系、销售、我的待办或系统运行卡片。标题“工作台”，副标题“查看项目进展与金额概况。”，不为隐藏区留空白占位。不新增指标、趋势、下钻、独立报表或现金流预测。
5. 移除财务角色撤销该身份权限，不新增负责人交接、通知或审批；账号停用仍按M06原规则使访问失效。其他兼任身份的独立权限和责任保持。

## 确认上下文与替代范围

用户2026-11-10提出“新增财务角色仅查看所有项目信息，工作台是项目看板”，在明确展示了全部六阶段、生态项目、附件及历史、仅工作台＋项目列表/详情、不开放框架/采购包/平台管理、复用项目概况的完整问题后答“是的”。问题及答案保存在原M11讨论“2026-11-10”，产品源任务 AI-TASK-20261110-FRAMEWORK-FINANCE-PRD-001。

本决定仅替代总PRD、Shared范围及Glossary中财务角色全局未纳入的边界；DEC-194关于M12不拥有财务核算/回款/开票/成本/毛利仍有效，M12不增加财务角色入口。原项目、商机、框架、员工和老师生命周期不改变。不根据历史财务提案恢复付款、核算或经营指标。
