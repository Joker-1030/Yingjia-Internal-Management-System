# P01 Acceptance Criteria

> Mechanical migration from the current full PRD. Stable IDs, wording, priority, and row order are unchanged.

| AC 编号 | Given | When | Then | 优先级 |
| --- | --- | --- | --- | --- |
| AC-F013-09 | 当前账号有 4 条以上消息且至少 2 条未读 | 打开浮窗和全部消息 | 浮窗只显示最新 3 条；抽屉分页显示全部；仅打开浮窗不自动标记全部已读，未读消息项保持红点和未读状态，侧栏角标保持同步 | P1 |
| AC-F013-10 | 同一任务提醒节点被调度重试 | 查看接收人消息 | 防重键保证只生成 1 条，其他不同节点仍可分别生成 | P0 |
| AC-F013-11 | 用户收到消息后失去对象权限 | 点击该消息 | 该条按明确点击转为已读并同步数量/红点/状态，但只显示对象不可用提示，不返回详情、附件、名称补充或缓存 | P0 |
| AC-F013-12 | 消息服务不可用 | 主业务成功并打开消息浮窗 | 主业务不回滚；消息进入重试，浮窗显示可重试错误且不显示他人缓存 | P0 |
| AC-F013-13 | 账号分别有 1、99、100 条未读，消息项显示未读红点 | 查看侧栏角标，点击一条消息，再执行全部已读 | 1-99 显示实际数量，100 显示 `99+`；点击一条仅将该条转为已读并同步数量与红点；全部已读后角标、全部红点和消息未读状态在同一结果内归零 | P1 |
| AC-F013-14 | AI 软件项目到达结束时间仍未确认交付 | 连续逾期并在第 3 天后继续未处理 | 到期立即及此后每天提醒项目负责人；满 3 天后同时每天提醒区域总监；确认交付、取消或中止后停止且不改变项目阶段 | P0 |
| AC-F013-15 | 培训项目已交付且资料或评价未齐全 | 连续逾期并在第 3 天后补齐，或项目进入终态 | 立即及此后每天提醒项目负责人；满 3 天后同时每天提醒区域总监；完成、取消或中止后停止；已中止且涉及金额结算时仅保留待回款只读提醒，消息失败不回滚项目 | P0 |
| AC-F013-16 | M12 商机的下次跟进日期为当天且持续无新有效跟进 | 连续运行消息任务并在第 3 个逾期自然日后新增有效跟进 | 当日上午提醒负责人，次日起每日一次，第 3 个逾期自然日同步区域总监；新跟进后旧承诺提醒停止，节假日不顺延，消息失败不改变商机事实 | P0 |
| AC-F013-17 | M12 方案支撑请求超过首次回应截止时间 | 支撑人员仍未有效回应，随后完成交付和关闭 | 向商机负责人和支撑人员直属主管发送一次超时节点消息；交付/关闭不删除历史超时事实，不产生审批或改变商机阶段 | P0 |
| AC-F013-18 | 用户完成 M02 调岗、M03 任务异常/逾期补录、M08 地市交接或 M12 指标调整 | 查看消息中心、侧栏角标和工作台待办 | 不生成审批待办、目标责任人接收待办、审批抄送或审批结果通知；只保留来源模块已定义的业务结果消息，且通知失败不回滚已生效业务事实 | P0 |
