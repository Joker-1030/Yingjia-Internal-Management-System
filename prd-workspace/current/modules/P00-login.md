# P00 登录页

- 文档状态：Supporting Product Facts（Current）；不作为独立 PRD Source of Truth
- 功能范围：登录与账号状态
- 原始事实章节：旧完整 PRD 第 179-254 行

## 模块目标

- 让员工使用现有账号手机号，通过短信验证码或密码进入系统；默认短信验证码登录。
- 在账号不可用、凭证错误、验证码错误或锁定时提供明确且不泄露账号事实的反馈。

## 用户角色

- 未登录用户使用登录页。
- 登录成功后的默认页面和数据范围由员工当前系统角色及责任事实决定；HR/人事固定进入 M06“组织与员工”。HR/人事从无权页面执行返回时同样进入 M06，不返回无权的 M01 工作台。

## 核心对象

- 员工账号
- 手机号登录标识
- 密码
- 图片验证码
- 短信验证码
- 登录会话

## 页面说明

- 登录页
- 提供“短信验证码登录”和“密码登录”两种方式，打开登录页默认选择短信验证码登录，可相互切换。
- 短信验证码登录：手机号、图片验证码、获取短信验证码入口、短信验证码输入框及登录按钮；图片验证码用于发送短信前校验，提交短信登录使用手机号和短信验证码。
- 密码登录：手机号、密码、图片验证码和登录按钮，保留密码显隐能力。
- Demo 演示账号快捷填充仅属于 Demo，不属于正式产品入口

## 功能列表

- 输入登录凭证
- 切换短信验证码登录或密码登录
- 校验图片验证码后获取、重发短信验证码
- 显示或隐藏当前密码输入
- 提交登录
- 接收错误、锁定或账号不可用反馈

## 状态

- 正常
- 提交中
- 验证码错误或失效
- 短信发送中、发送失败、等待再次发送
- 手机号或密码错误
- 账号锁定
- 员工或账号停用

## Demo 登录演示约定

- 本节仅描述已有密码登录的图片验证码演示，不是短信验证码自动填充或真实发送规则；短信登录正式需求见下文，不能用现有Demo代替该需求验收。
- 仅当前 Demo：图片验证码自动填入现有输入框，演示者无需手填。首次打开登录页、点击验证码刷新、每次提交后的验证码更新、退出登录返回时，输入框均同步为当前新验证码；点击演示账号快捷填充时也填入当前验证码。保留验证码图片、输入框及刷新入口。

- 以下“关键登录规则”、正式登录 Flow 和 Acceptance 描述正式产品要求，其中验证码清空且不回填答案的要求在 Demo 中由本节明确例外替代，不能将 Demo 便利操作用于正式产品。

## 关键登录规则

### 两种方式共用的账号与会话规则

- 两种方式使用 M06 维护的同一个员工账号及其当前手机号。仅现有在职且账号启用的员工可以登录；短信登录不创建员工或账号，不改变角色、责任和权限范围。
- 员工或账号停用时，两种方式均禁止登录。密码连续错误触发的30分钟锁定对两种方式共同生效：锁定期间即使密码或短信验证码正确也不能登录，不能通过切换方式绕过锁定；锁定到期后按原规则清零密码错误次数。
- 无论验证码获取时账号是否可用，登录提交时均以当前员工、账号及锁定状态为准。
- 两种方式成功登录均更新最近登录时间、清零连续密码错误次数，并使用相同会话时限和角色默认有权页面；HR/人事进入M06组织与员工。会话闲置30分钟、单次登录最长12小时，详见 [`prd-workspace/current/shared/03-unified-product-rules.md`](../shared/03-unified-product-rules.md) → “密码与登录安全”。
- 发送及登录反馈沿用不泄露手机号是否存在、凭证答案和内部安全信息的边界；不得通过短信登录扩大员工手机号的页面可见范围。

### 密码登录

- 密码登录先校验图片验证码。验证码错误或失效时，只清空并刷新验证码，不累计密码错误次数；手机号和密码输入保留，密码恢复掩码。
- 验证码错误反馈只说明验证码错误或已失效，不展示、暗示或回填正确答案。
- 仅在图片验证码正确、账号存在且可用时校验密码并累计连续密码错误次数。连续第 5 次密码错误后，账号锁定 30 分钟；页面不展示剩余可尝试次数。
- 密码错误时保留手机号、清空密码并刷新图片验证码，使用不泄露账号存在性或正确凭证的通用错误反馈；该次错误计入连续密码失败次数。
- 锁定期间即使密码正确也拒绝登录；锁定到期后连续密码错误次数清零。账号不存在、员工或账号停用、账号已锁定或登录服务异常时，不累计该手机号的密码错误次数。
- 登录成功后，同一图片验证码立即失效。
- 完整分支见 [`prd-workspace/current/user-flows/FLOW-01-P00-login.md`](../user-flows/FLOW-01-P00-login.md) → “密码登录流程”；锁定与登录交互验收见 [`prd-workspace/current/acceptance/M06.md`](../acceptance/M06.md) → AC-F001-20、AC-F001-32、AC-F001-33、AC-F001-43、AC-F001-44。

### 短信验证码登录

1. 输入现有账号手机号，校验图片验证码后申请发送短信验证码。每次发送（含重发）前都须通过图片验证码校验；图片验证码沿用现有4位、5分钟有效、校验提交后不可复用及刷新规则。图片验证码错误或失效不发送短信，不累计密码错误次数，也不泄露正确答案。
2. 短信验证码为**6位数字**，与接收手机号绑定；发送成功后**5分钟有效**。输入的手机号与验证码必须匹配，不能将其他手机号收到的验证码用于登录。
3. 同一手机号发送成功后**60秒**才可重新发送。等待期间不可再次发送；切换登录方式或重新打开页面不能绕过重发间隔。
4. **重发成功后旧短信验证码立即失效**，新码重新按5分钟有效期处理；重发失败不视为新码发送成功，也不因失败延长原码有效期。发送异常只反馈失败，不建立登录会话。
5. 提交手机号和短信验证码登录，无需输入密码。验证码错误、过期或已失效均不能登录；同一有效验证码连续**输错5次后失效**，需重新获取。短信验证码错误不计入密码错误次数，不另触发密码错误锁定。
6. **登录成功后，本次短信验证码立即作废**，不可重复使用。重发成功作废、有效期届满、输错5次作废和成功登录作废均须执行，不能靠切换方式或重复提交恢复验证码。
7. 登录提交同时执行上文的员工/账号可用性和30分钟锁定限制；短信验证码正确不等于可以绕过停用或锁定。

完整流程见 [`prd-workspace/current/user-flows/FLOW-01-P00-login.md`](../user-flows/FLOW-01-P00-login.md) → “短信验证码登录流程”；验收见 [`prd-workspace/current/acceptance/M06.md`](../acceptance/M06.md) → AC-F001-65至AC-F001-70。短信登录属于P00身份验证，不放开P01业务通知的短信发送渠道。

## 退出登录规则

- 用户点击退出登录后，显示二次确认弹窗：标题为“确认退出登录”，正文为“退出后将返回登录页面，是否继续？”，按钮为“取消 / 确认退出”。
- 取消或关闭弹窗不改变当前登录状态；确认退出后结束当前会话，清除当前客户选择和本地敏感信息，并返回登录页。
- 退出弹窗不展示 Demo 环境、内存数据或刷新后恢复初始数据等演示说明；完整退出结果见 [AC-F001-46](../acceptance/M06.md)。

## 权限边界

- 登录失败提示不得泄露手机号是否存在或密码是否正确。
- 登录后权限由角色模板、数据范围和当前责任事实共同决定。

## 不包含

- 用户名登录
- 第三方登录
- 自助注册、短信自动创建员工账号、短信找回密码或手机号自助换绑
- 记住账号
- 生产会话或密码存储实现方式
