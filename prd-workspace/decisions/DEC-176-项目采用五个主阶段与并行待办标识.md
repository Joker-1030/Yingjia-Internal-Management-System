# DEC-176：项目采用五个主阶段与并行待办标识

- 日期：2026-08-27
- 状态：部分被 DEC-201 替代；主阶段与并行待办分离、交付和自动完成规则继续有效，五阶段枚举及取消阶段范围不再作为 Current Rule
- 背景：资料、评价和回款可以同时未完成，若与项目阶段混为单一状态，会形成互斥冲突并让交付、完成和取消边界不清晰。
- 决策：项目主阶段固定为`已立项`、`进行中`、`已交付`、`已完成`、`已取消`；`资料待上传`、`待评价`、`待回款`是可并行待办标识。培训项目到结束时间自动交付，AI 软件项目由负责人确认交付；项目在已交付且资料、项目满意度及适用人员满意度齐全后自动完成，回款不阻塞。当前取消直接生效且已完成不可取消；未来统一审批中心上线后再接入取消审批。
- 未采用方案：把七类文案都作为互斥阶段；回款完成后才允许项目完成；当前分散建设项目取消审批。
- 原因：主阶段表达项目履约生命周期，待办标识表达可并行缺口，二者分离后状态唯一且可验收。
- 决策人：Product Owner
- 影响范围：M01、M11、P01、Acceptance、FLOW-15、Shared、Glossary、Product Boundary

> 替代说明（2026-09-04）：`DEC-201《项目取消收紧并新增进行中中止与结算记录》` 将项目主阶段扩展为六态，仅已立项可取消，并为进行中项目增加直接中止及条件结算记录。本文关于进行中/已交付可取消及“五个主阶段”的表述仅作 Historical / Replaced Evidence。
