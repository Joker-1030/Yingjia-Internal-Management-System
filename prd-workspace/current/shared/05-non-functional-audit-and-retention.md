## 附录 C：非功能、日志与数据保留

| 类别 | 实施要求 |
| --- | --- |
| 性能 | PC 首屏 P95 <= 3 秒；普通列表 P95 <= 1 秒；5000 个有效客户节点首次结果 <= 2 秒；超量树按需加载 |
| 并发 | 支持 100 名在线用户、30 个并发写请求；任务生成、导入和审批回调无重复 |
| 可用性 | 普通读写月可用性目标 99.9%；上游失败按功能降级，不显示伪造成功 |
| 安全 | 全站 HTTPS；密码强哈希；对象级鉴权；附件受控；手机号、邮箱、文件地址和密码不进入普通日志 |
| 兼容 | Chrome、Edge 最近两个主版本；最低 1366x768；本期不承诺移动端业务操作 |
| 监控 | 登录、权限、任务调度、审批回调、通知、导入、附件均输出结构化日志、请求 ID 和告警 |
| 备份 | 数据库每日备份；RPO <= 24 小时，RTO <= 4 小时 |
| 保留 | 客户、关键人、任职、任务、记录、审批和审计长期保留；消息至少保留 3 年；临时附件 24 小时 |
