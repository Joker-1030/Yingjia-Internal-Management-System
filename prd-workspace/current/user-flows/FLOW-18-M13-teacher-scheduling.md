# FLOW-18 M13老师建档与排期

- 状态：CURRENT；Product Review：NOT REVIEWED；日期：2026-11-03。
- Owner：[`M13 培训老师管理`](../modules/M13-teacher-management.md) §3至9；关联 [`M11 项目管理`](../modules/M11-project-management.md) §9。

## 建档与维护

1. admin在M06关联老师/教学管理人员角色；admin、总裁、市场副总在M13给全部教学管理人员分配内部/机构渠道/个人渠道范围，师资管理部主管仅为本部门教学管理人员分配。
2. 从“老师管理”菜单，admin/有权管理者新建档案，内部选择老师角色员工，外部填写公共资料和至少一个渠道；两类均填写至少一项授课类型及有效常驻省市；多机构共享同一档案排期。
3. 老师手机号/微信号至少填写一项（邮箱不可替代），已填手机号/微信按通用格式复核；内部手机号仍复用员工资料。性别可留空或下拉选择男/女，学历可留空或下拉选择高中及以下/中专/大专/本科/硕士/博士。教学方向可搜索多选、候选限高且默认收起，已选持续可见；渠道紧凑显示名称、逐项展开，添加时只展开新项，折叠保留全部输入，错误展开定位。验证必填、所选采购包课程、联系格式和有权渠道；简历沿用通用附件规范，内部按三角色分别填写对外标准/内部结算参考价，外部每渠道按三角色填写参考价，课酬行随已勾选授课类型实时显示，内部及所有渠道一致；取消再勾选保留原价格及逐条税务，保存后仍保留；不产生项目费用或实际结算。失败保留输入、整体不保存；成功刷新。
外部老师在原档案新增/编辑中选择与我司合作的“合作属性”（独家/非独家，可留空且无默认），不按渠道拆分；原维护权限/范围/版本及取消、失败原子性保持。管理列表来源处及管理详情展示，未标记显示“—”，内部不展示/保存，项目资料不增加字段；不改变课酬、排期或选师资格。真实存量核实补录、不推定，Demo无迁移适配。

4. 管理端列表支持姓名、来源、授课类型、常驻省市、教学方向、状态及合作属性AND查询/重置，默认全部，独家/非独家筛选仅命中相应外部老师、内部或未标记不命中，矛盾条件沿空反馈；查询/重置回首页；操作保留已应用条件、登录重置。老师“我的信息”直接展示本人资料及原联系方式，无列表/详情按钮、排期或不可用入口。管理端详情按范围输出公共资料、联系方式及有权渠道/费用/简历，课酬只显示已勾选授课类型；仅有项目身份的用户及老师本人不获得简历访问。取消/关闭不保存。
5. 修改方向前检查老师作为主讲/辅训参与的已立项/进行中项目；移除其所用方向则阻止保存、保留原档案并提示受影响项目。项目负责人先按原阶段权限更换老师或调整项目，再由管理者重试；仅任助教不要求方向，不改写已交付历史。

6. 取消授课类型提交时，弹窗说明已创建项目按原已选身份继续执行、后续新选按更新类型，并列出全部关联项目名称、当前阶段及当前负责PM（生态项目显示生态负责人）。无关联项目也确认；返回修改/关闭/遮罩取消不保存且保留表单。确认前复核权限/版本及关联清单，项目清单或阶段/负责人变化重新展示确认，确认后整体保存，不改写已有项目。

## 项目选师

1. 在M11原有创建/编辑入口，采购包课程和平台师资合作培训项目均先选采购包、再选包内一门课程，填写开始/结束时间；老师教学方向多选同一来源的包内课程，不设独立方向目录或额外配置；原平台合作课酬保持。
2. 按主讲/辅训/助教槽位拉取相应授课类型，展示类型和公共常驻省市，只返回整段日期有空且适用方向匹配的启用老师；内部还须员工在职且有有效老师角色；主讲/辅训匹配方向，助教不要求方向。
3. 保存再校验新增/替换人员相应授课类型（已创建项目原已选身份不因取消类型失效）及资格（含内部员工/角色有效性）、人工不可用、其他项目全天占用及原项目阶段权限，排除自身占用；失效员工不能通过旧表单被新选/替换加入。失败不改项目，保留选择并提示原因，无强制覆盖。
4. 保存后项目成为老师排期的只读来源；原项目取消、中止释放后续排期且保留历史。

## 不可用与停用

1. 教学管理人员从“老师排期→登记不可用日期”选择原范围内可维护老师（默认空，必选）和原起止日期，详情不再提供新增；候选不受日历老师筛选缩小，无候选/无维护权不显示入口。保存复核账号、最新范围/权限/版本及原日期/冲突，失败保留输入、取消不保存，成功保留当前月/老师筛选/视图并留排期页。原详情编辑/删除及admin/总裁/市场副总/师资管理部主管入口保持；内部老师在“我的排期”新增、修改、删除本人登记的人工不可用，原本人全部安排列表随月历集中到该页，其他登记和项目只读。成功留排期页并保留月份、不打开资料抽屉；原确认、冲突/版本/权限和失败保持。
2. 所有有权登记者（含教学管理人员、老师本人）在新增/编辑不可用表单填写必填“备注/原因”；去首尾空白后非空，缺失提示并保留老师/日期/内容、整体不保存。编辑回显原原因；与已安排项目冲突则阻止并提示项目，项目负责人先调整；无冲突保存到统一排期，原因在原范围内安排列表及不可用日程详情可见，老师本人可读管理人员登记原因但无改删资格。真实存量缺失不编造，显示“—”，后续编辑补填；Demo新样例不兼容旧数据。
3. 停用前检查全部未开始/进行中授课项目，有则须先换老师；已交付待资料/评价不阻断。
4. 确认停用只退出新选，保留历史及员工账号；恢复重新按方向和空闲参与候选，无自动改派或补造历史。
5. 若M06停用内部员工或移除老师角色，立即退出新选/替换，即使老师档案仍启用；已有项目、排期和历史保留，由项目负责人另行调整。员工停用时员工及账号按M06原规则立即失效，不等待换师；仅撤老师角色不因此停用整个账号，不自动修改老师档案状态或改派项目。

## 查看日历与甘特图

1. 从独立“老师排期”菜单进入视图，不与“老师管理”的档案列表混排；档案和排期菜单向总裁、市场副总开放全部老师管理资格（与admin相同）。老师身份对应“我的排期”，“我的排期”菜单在“我的信息”上方，纯老师每次登录进入本月，“我的信息”直接展示本人资料且不含排期；admin/总裁/市场副总/教学管理人员使用“老师排期”，兼任沿有效角色和原落地优先规则。内部老师进入本人日历，默认北京时间当前月，只返回本人安排；可切月份，不提供他人筛选或单独老师角色的甘特图。
2. 总裁、市场副总从“老师排期”进入，默认当前月/日历/全部内部与外部老师，可单多选或切月份、切甘特图并保留条件；日程点击仍只读，档案、简历、完整联系方式、渠道课酬及不可用/启停维护从老师管理的原入口进行，可为全部教学管理人员配置三项范围；原经营工作台落地、M06员工和M11项目权限保持。
3. 教学管理人员默认进入日历及当前月，展示全部负责老师；可筛选一名/多名，候选与日程均遵守原三项管理范围。管理端展开“选择老师”下拉多选，候选向下贴齐控件左侧并限高滚动；连续勾选/取消老师或全选时立即刷新排期且保持列表展开，再点控件或外部收起。原默认、范围、空选反馈与月份/视图保留规则不变，老师个人端仍无此筛选，登记不可用弹窗仍单选老师。
4. 查看当前月内的授课占用和人工不可用，跨多天连续展示，跨月安排展示与当前月重叠部分；占用口径和历史保留按原规则。
5. 管理人员、总裁或市场副总切换甘特图，以老师为行、自然日期为列；共用当前月份及老师筛选，切换视图保留条件且不改变排期。
6. 点击日程只读查看既有安排及起止日期；项目详情仍按M11原权限，无权不能借日程跳转。不提供拖拽改期或项目人员修改，不扩大联系方式/简历/课酬权限；人工不可用仍从既有有权入口维护并校验冲突。

## 框架培训选师（DEC-243）

M11框架服务培训不选课程，完成日期后按三槽对应授课类型、启用/内部员工资格及完整排期取人，主讲至少一人；新增/替换和日期编辑提交复核，排除自身项目占用。不要求课程方向，不改变其他资源匹配、原已选类型保留及软件不选择授课人员。Owner：`prd-workspace/current/modules/M13-teacher-management.md` → §6“框架服务选师例外”；验收AC-M13-33、AC-M11-87。
