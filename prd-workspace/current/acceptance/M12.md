# M12 Acceptance Criteria

| AC 编号 | Given | When | Then | 优先级 |
| --- | --- | --- | --- | --- |
| AC-M12-01 | 用户进入当前系统 | 查看导航和 M12 页面 | 系统只有“销售与商机管理”入口，不出现独立“线索”菜单、对象、字段或转商机流程；早期机会直接以商机录入/需求确认阶段存在 | P0 |
| AC-M12-02 | 总裁、市场副总、区域总监、PM、HR 和系统管理员分别登录 | 查看仪表盘、商机列表并直接访问对象 | 总裁/市场副总/区域总监/PM 按公司/全国市场/主管区域并集/本人负责商机查看；系统管理员公司全局；HR 无入口且直接访问 403 | P0 |
| AC-M12-03 | 某月公司商机数量目标为 12，区域合计为 11 | 发布区域分配 | 系统指出月份和差额并禁止发布，不生成生效版本 | P0 |
| AC-M12-04 | 公司、区域和 PM 首次分配均守恒，随后市场副总和区域总监调整已发布目标 | 依次发布和调整 | 首次分配直接生效；区域调整进入总裁审批，PM 调整进入市场副总审批，市场副总缺位时由总裁处理；审批前原版本继续有效 | P0 |
| AC-M12-05 | PM 在本月发生调区且存在历史月份目标 | 有权人员调整指标 | 只能调整当前月及未来月份；历史月份和事件归属不变，调整后继续满足上下级守恒 | P0 |
| AC-M12-06 | 当前存在跨周期商机及新建、中选、落选事件 | 切换年、季度和月 | 商机数量目标/完成及新建趋势按周期变化；全部商机、活跃商机、漏斗和覆盖保持当前快照并有明确区分 | P0 |
| AC-M12-07 | 当前有比选、中选和落选商机 | 查看仪表盘 | 活跃金额使用比选预估金额加中选预计签约金额；中选率只使用中选与落选结果；只有历史落选的客户不算当前覆盖 | P0 |
| AC-M12-08 | PM 只负责济南范围客户 | 新建商机并打开客户和关键人候选 | 只出现有权正常客户，关键人只来自选中客户；客户集团、行业和业务责任事实只读派生，不在商机重复维护 | P0 |
| AC-M12-09 | 新建表单缺少首次跟进日期，随后补齐其他必填字段和有效日期 | 提交创建 | 首次提交不生成商机或支撑请求；补齐后只生成一个永久编号、创建时间、商机录入记录和当前跟进承诺 | P0 |
| AC-M12-10 | 商机处于需求确认 | 尝试跳到比选、退回商机录入，随后正常进入方案支撑 | 跳过和退回均被拒绝且无历史；正常下一阶段成功并保留不可覆盖的阶段记录 | P0 |
| AC-M12-11 | 商机处于比选或中选 | 分别缺少中选字段进入中选、由非负责人代推进、由负责人完整提交落选 | 缺少字段和非负责人请求被拒绝；完整落选进入终态并冻结停留时间；M12 不显示已签约入口或状态 | P0 |
| AC-M12-12 | 区域内有两名有效 PM | 区域总监填写原因改派，随后尝试改派给区域外或停用员工 | 合法改派保留前后负责人和时间，历史事件归属不重写；非法候选不可选且直接请求被拒绝 | P0 |
| AC-M12-13 | 一条商机向两名员工发起方案支撑 | 两人分别响应、交付，其中一人超时，再由负责人确认或要求补充 | 两条请求按待响应、已响应、支撑中、已交付、已关闭独立流转和计时；超时消息发送给负责人和对应人员主管；补充及关闭历史保留 | P0 |
| AC-M12-14 | 员工仅因被指派方案支撑可见商机 | 查看详情并直接访问指标、其他商机或客户经营对象 | 只可见完成支撑所需的客户、需求和方案内容，不获得销售指标、其他商机或客户范围 | P0 |
| AC-M12-15 | 未落选商机的下次跟进日期为当天且连续 3 个自然日无新记录 | 运行提醒并在其后新增有效跟进 | 当日上午提醒负责人，次日起每日一次，第 3 个逾期自然日同步区域总监；新跟进形成未来日期后旧提醒停止，节假日不顺延 | P0 |
| AC-M12-16 | 用户打开 M12 指标、列表、详情和操作区 | 查找合同、财务、回款、开票、成本、毛利和已签约能力 | 页面不存在上述维护入口、角色和状态；未接入事实不显示为 0；M11 当前人工创建项目入口和规则保持不变 | P0 |
