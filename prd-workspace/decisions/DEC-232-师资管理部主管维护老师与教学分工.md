# DEC-232 师资管理部主管维护老师与教学分工

## 当前决定

1. 当前担任“师资管理部”部门主管的员工，按组织主管关系获得 M13 的特定业务资格，不新增系统角色或角色模板。
2. 该主管可维护全部三类老师：内部老师、外部机构渠道老师、外部个人渠道老师；可查看和维护老师档案、公共资料、完整联系方式、渠道、课酬、简历、排期、启停及人工不可用日期。
3. 该主管可进入“培训老师 → 老师管理 → 教学管理范围”，为师资管理部内的教学管理人员配置“内部老师、外部机构渠道、外部个人渠道”三项范围，三项可多选。admin仍可为全部教学管理人员配置。
4. 其他部门主管、普通 HR/人事及其他角色不因主管关系或员工编辑权限获得上述资格。师资管理部主管资格随当前部门主管关系识别，主管关系变更后随之生效。

## 边界

- 不新增员工角色，不改变 M06 的员工/账号事实，也不改变 M07 角色模板维护范围。
- 教学管理范围配置对象限定为师资管理部内的教学管理人员；admin的全局配置范围保持。
- 老师方向仍复用 M11 采购包内课程，排期、隐私、简历、课酬和项目选师规则沿 M13 当前规则。
