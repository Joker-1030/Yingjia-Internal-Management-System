- 文档类型：模块化 PRD 人类阅读入口
- 文档状态：Active；M01-M10 已于 2026-08-24 成为正式模块化 PRD Source of Truth
- 产品阶段：立项与需求澄清 / 待产品评审
- 产品范围：基础权限与客户管理
- 适用终端：PC Web

本文件用于快速理解产品和定位正式模块化 PRD。页面字段、完整校验和模块业务规则以 M01-M10 对应文件为准；Acceptance、Decision、Flow、Shared、Glossary 和 Product Boundary 通过下方入口提供可追溯约束。

## 产品介绍

### 产品目标

- 使用稳定对象沉淀客户、关键人、任职、维系动作和历史记录，避免人员变动造成客户资产丢失。
- 以组织员工、系统角色、区域与地市责任形成账号权限和客户责任的产品事实。
- 支持维系任务生成、执行、审批、统计和追溯。
- 让列表、搜索、详情、附件、导入和直接访问使用一致的数据范围。
- 为用户可见的表单、状态变化和异常提供明确反馈。

### 使用范围

本期覆盖登录、工作台、客户经营、维系管理、审批、停用记录、消息、组织员工、权限授权、区域地市配置、客户基础配置和数据导入。

本期不包含销售管理、商机、方案支撑、合同、财务、项目管理、项目进度或项目材料。后续业务通过稳定客户公司和关键人 ID 关联，不复制本期客户主数据。

### 用户角色

| 角色 | 主要产品立场 |
| --- | --- |
| 总裁 | 公司全局经营、审批和管理查看 |
| 市场副总 | 全国市场执行、规则查看、专项及区域相关管理 |
| 区域总监 | 本人主管区域的监管、地市责任和省公司业务 |
| PM | 本人负责地市的客户、关键人和维系任务执行 |
| HR/人事 | 公司组织、员工、账号和人员异动维护，无客户经营权限 |
| 系统管理员 | 公司全局全部业务和技术维护权限，独占权限授权 |

完整权限和数据范围见 [角色、权限与数据范围](./shared/01-roles-permissions-and-data-scope.md)。

## 核心原则

### 权限边界

- 权限同时受菜单/页面、操作、字段、附件和对象数据范围约束。
- 无权入口不可见，伪造请求不得返回越权对象信息。
- 系统管理员为公司全局全权限账号，但操作必须记录真实管理员身份，不改写业务责任快照。
- 权限授权仅系统管理员可访问；其他角色不能通过兼任获得该入口。

### 数据可见性

- 总裁使用公司全局范围，市场副总使用全国市场范围。
- 区域总监使用本人主管的全部区域中心并集。
- PM 使用当前有效负责地市范围。
- HR/人事使用公司组织范围，不获得客户业务范围。
- 搜索、列表、计数、详情、附件、导入和直接访问使用相同范围。

### 产品事实所有权

- 内部组织与员工事实归 M06。
- 角色模板权限归 M07。
- 区域与地市责任归 M08。
- 客户主数据和客户组织树配置归 M09。
- 客户资产日常使用归 M02，任务生命周期归 M03，通用审批处理归 M04。
- 关联关系不自动授权跨模块修改。

### 状态与反馈

- 页面必须表达正常、加载、空、错误和无权限等可见结果。
- 操作必须表达提交中、成功、失败、阻断和冲突反馈。
- 页面反馈状态不替代业务对象生命周期，也不新增业务规则。
