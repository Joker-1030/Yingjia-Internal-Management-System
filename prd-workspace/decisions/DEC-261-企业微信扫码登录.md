# DEC-261 企业微信扫码登录

- 日期：2026-11-26；状态：已确认 / NOT REVIEWED / NOT STARTED。
- Owner：P00 登录页；关联 M04 审批中心、M06 组织与员工。
- 类型：NEW / CHANGE；影响：HIGH；Product Concept Delta：NEW AUTHENTICATION METHOD；Approved Baseline：UNKNOWN。

## 确认来源

Product Owner 明确要求“登录支持企业微信扫码登录”。当前企业微信员工绑定已由 M04/M06 定义为双方已有员工的一对一关系，本决定将该绑定用于登录身份识别；不改变原有账号、组织、角色和权限事实。

## 当前决定

1. 登录页在短信验证码和密码登录之外增加“企业微信扫码登录”，默认登录方式仍为短信验证码登录，三种方式均建立同一类平台登录会话。
2. 扫码授权返回的企业微信员工必须命中 M06 已维护的一对一绑定，且对应平台员工在职、账号启用并未被临时锁定；未绑定、冲突绑定、停用或锁定均拒绝登录。
3. 扫码成功后复用绑定的平台员工账号，沿用原角色、责任范围、权限、默认落点、会话时限和员工使用统计；不自动创建平台员工/账号，不同步覆盖平台部门、主管、角色、客户责任或权限。
4. 平台不提供登录页员工选择。二维码刷新使当前授权失效；二维码有效期、轮询/回调、错误码和异常重试依实际企业微信接口验证后落实现状，不在本决定中虚构接口能力。
5. Working Demo使用可点击的模拟扫码入口表达成功和失败边界，不代表已接通企业微信真实扫码接口；真实接口接入仍属于 M04 延期、未评审、未研发范围。
