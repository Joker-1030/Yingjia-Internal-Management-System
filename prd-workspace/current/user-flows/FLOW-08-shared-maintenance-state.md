```mermaid
stateDiagram-v2

    补录审核中 --> 当前逾期: 业务上级驳回
    当前逾期 --> 已完成: 常规任意后续日期补完成，或其他类型仍在窗口
    当前逾期 --> 当前逾期: 常规持续未完成，无最晚窗口
    当前逾期 --> 已过期未完成: 生日/节假日/专项超过规则窗口
    待执行 --> 已过期未完成: 生日/节假日规则不允许补完成且越过截止
```
