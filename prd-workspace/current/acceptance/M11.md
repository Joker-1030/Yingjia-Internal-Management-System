# M11 Acceptance Criteria

> Current acceptance for M11 项目管理。项目本体行为由 M11 拥有；工作台、地区责任交接、导入和消息的跨模块结果同时由对应模块 Acceptance 约束。

| AC 编号 | Given | When | Then | 优先级 |
| --- | --- | --- | --- | --- |
| AC-M11-01 | 当前人工创建阶段，PM、区域总监和 admin 分别登录 | 创建市级/区县级业务责任客户、省级业务责任客户和公司范围项目 | PM 仅可选本人责任地市内的市级/区县级业务责任客户，区域总监仅可选本人负责的省级业务责任客户，admin 可选公司客户；候选和权限只按业务责任事实计算，越权候选和请求均被拒绝 | P0 |
| AC-M11-02 | 客户业务责任区域没有有效区域总监或 PM | 任一角色包括 admin 提交创建 | 阻止立项，不生成项目或编号，不出现“负责人待分配”项目；合法组织上级不能替代负责人校验 | P0 |
| AC-M11-03 | 当前人工创建可用且初始化已经结束，但商机/合同能力尚未上线 | 有权角色打开创建入口 | 人工创建继续可用；只有商机/合同能力正式上线后才关闭 | P0 |
| AC-M11-04 | 商机/合同能力已正式上线且合同未通过或已通过 | 用户尝试普通人工创建或商机负责人从商机创建 | 普通入口关闭；未通过合同不能创建；通过后带出商机、合同、客户和负责人并在补齐字段后直接立项，不增加项目审批 | P0 |
| AC-M11-05 | 用户打开创建页后放弃、提交校验失败或成功立项 | 查看编号序列 | 前两种不占号；成功项目获得当年唯一 `XM` 编号；取消后编号不回收 | P0 |
| AC-M11-06 | 当前未取消项目已经使用某名称，另有已取消项目保留旧名称 | 创建或修改项目名称 | 当前占用名称被拒绝；已取消项目的旧名称可复用；取消记录仍保留原名称 | P0 |
| AC-M11-07 | 项目已立项 | 尝试修改客户、锁定的业务责任地区或项目类型，或在 M09 调整客户组织上级 | 项目字段锁定；客户错误只能取消后重新创建；组织上级调整不改变项目客户引用、负责人或历史客户快照 | P0 |
| AC-M11-08 | 省级、市级和区县级业务责任客户分别立项 | 查看创建负责人快照和当前负责人 | 省级匹配区域总监，市级/区县级匹配业务责任城市 PM；所属集团、组织上级和组织路径均不参与匹配，创建快照和当前负责人均可追溯 | P0 |
| AC-M11-09 | 同日或跨日项目使用 12:00 分界，系统形成系统计算天数和项目确认天数 | 用户查看、修改日期或手工修改项目确认天数 | 系统计算天数按自然日规则产生且只读；项目确认天数默认同步，未手工修改时随日期继续同步，手工修改后日期变化只更新系统计算天数；确认值最小 0.5 且为 0.5 的整数倍 | P0 |
| AC-M11-10 | 培训项目选择采购包课程或平台师资合作 | 选择资源并填写时间和项目确认天数 | 项目单价分别取课程含税报价或平台合作课酬，项目金额等于单价乘项目确认天数；AI 软件项目确认天数不参与项目金额计算 | P0 |
| AC-M11-11 | AI 软件项目选择允许的资源与合作形式 | 填写项目金额 | 不展示或使用按天项目单价，项目金额由负责人填写 | P0 |
| AC-M11-12 | 直接服务、师资合作和走账合作项目金额相同 | 计算结账金额 | 前两者等于项目金额；走账合作按管理费比例扣减；金额和比例按已确认精度四舍五入 | P0 |
| AC-M11-13 | 用户组合资源类型与合作形式 | 选择采购包课程、平台师资合作或 AI 区域框架 | 仅允许已确认组合；AI 区域框架只对 AI 软件项目开放；直接服务不关联平台公司 | P0 |
| AC-M11-14 | 项目创建时选择采购包/平台公司，之后配置发生变化 | 查看既有项目 | 既有项目继续显示创建时商业快照，不被追溯改写 | P0 |
| AC-M11-15 | 项目尚未开始或已经开始 | 调整采购包、课程方向、合作形式或平台公司 | 开始前允许并整体刷新商业快照；开始后字段与快照锁定 | P0 |
| AC-M11-16 | admin、总裁、市场副总、区域总监、PM、HR/人事分别进入采购包/平台公司页面或伪造维护请求 | 查看并尝试新增、编辑、停用或恢复 | 仅 admin 可查看全部配置并执行新增、编辑、停用和恢复；总裁、市场副总、区域总监和 PM 只读查看当前正常有效配置，页面不显示维护入口且伪造维护请求不生效；HR/人事无页面和 M11 数据权限 | P0 |
| AC-M11-17 | 采购包或平台公司停用，且已有项目引用 | 创建新项目并查看旧项目 | 停用配置退出新候选；旧项目按快照继续有效；对象不可物理删除且编号不回收 | P0 |
| AC-M11-18 | 当前没有正式讲师库 | 创建培训项目 | 从虚拟讲师候选选择至少 1 名主讲师；辅讲师和助教可空或多选；AI 项目不展示人员字段 | P0 |
| AC-M11-19 | 选择/调整项目人员或修改影响排期的时间，与其他有效项目重叠 | 保存 | 阻止保存并展示冲突人员、时间和关联项目编号；任何角色不能强制覆盖 | P0 |
| AC-M11-20 | 项目到达开始时间，随后分别为培训项目和 AI 项目到达结束时间 | 查看主阶段 | 均自动进入进行中；培训项目自动进入已交付，AI 项目保持进行中直至负责人确认交付 | P0 |
| AC-M11-21 | 培训项目或已确认交付的 AI 项目处于已交付 | 资料、项目满意度和适用人员满意度逐步补齐 | 缺项显示并行待办；全部必填齐全后自动完成；待回款不阻塞 | P0 |
| AC-M11-22 | 项目处于已立项、进行中、已交付或已完成 | 尝试填写或修改满意度 | 仅已交付可填写；已完成后完全只读，admin 也不能修正 | P0 |
| AC-M11-23 | 培训项目选择多名主讲师、辅讲师和助教 | 填写满意度并尝试完成 | 项目和每名主讲师必填；已选择辅讲师/助教均需对应评分；缺任一项不能完成 | P0 |
| AC-M11-24 | AI 软件项目已交付 | 补齐当前规定资料和项目满意度 | 自动完成且不要求讲师评分 | P0 |
| AC-M11-25 | 项目分别处于已立项未开始、进行中和已交付 | 编辑字段 | 只开放 M11 阶段矩阵允许字段；资源开始后锁定，人员变化按要求填原因并留痕 | P0 |
| AC-M11-26 | 进行中培训项目修改结束时间 | 保存且无排期冲突 | 重新计算系统计算天数；确认值未手工修改时同步更新，已手工修改时保留；项目金额和结账金额按项目确认天数重算，并记录两个天数、金额前后值、操作人和时间 | P0 |
| AC-M11-27 | 已交付项目实际人员与原安排不同 | 项目负责人或 admin 代操作修正 | 要求填写原因，保留人员前后值和实际操作人；不改变已交付阶段 | P0 |
| AC-M11-28 | 已完成项目存在可选资料可补充 | 当前负责人、历史原负责人和 admin 分别操作 | 当前负责人可新增不可删除/替换；历史原负责人失权；admin 可代操作并留痕；阶段不变 | P0 |
| AC-M11-29 | 项目处于已立项、进行中、已交付、已完成 | 有权人尝试取消 | 前三类可填写原因直接取消；已完成不可取消；取消后只读不可恢复、清除待办并释放人员排期 | P0 |
| AC-M11-30 | 区域总监查看本人省级项目和区域内 PM 项目 | 尝试取消 | 只能取消本人负责的省级项目；PM 项目只允许对应 PM 或 admin 取消 | P0 |
| AC-M11-31 | admin 代项目负责人编辑、取消或补充资料 | 查看详情和历史 | 操作遵守同一阶段边界，展示实际管理员，保留业务负责人和完整操作记录 | P0 |
| AC-M11-32 | PM 或区域总监地区责任发生正式交接 | 交接生效 | 已立项、进行中、已交付和已完成项目随责任同时转移；取消项目不转移；原负责人保留在历史 | P0 |
| AC-M11-33 | 地区责任交接或直接调整遗漏项目，或任一适用项目迁移失败 | 提交或生效责任变化 | 整体阻断并保留原地区责任与项目负责人，不形成由该次主动交接造成的负责人空档；不允许单项目脱离地区责任转交 | P0 |
| AC-M11-34 | 项目列表存在多类型、阶段、待办、客户、地区和负责人数据 | 分别填写项目编号、项目名称、开始时间、结束时间及其他组合筛选 | 项目编号只匹配项目编号，项目名称只匹配项目名称；开始时间有值时匹配项目开始时间不早于所选值，结束时间有值时匹配项目结束时间不晚于所选值；多个已填字段按 AND 取交集，结果、数量和操作均在当前范围内，且每个筛选控件具有常驻可见字段标签 | P1 |
| AC-M11-35 | 用户进入项目详情 | 查看五个 Tab 和顶部操作 | 显示基本信息、人员安排、资料、满意度、变更与责任历史；操作按钮按角色和阶段出现，无权用户只读 | P1 |
| AC-M11-36 | 上传项目视频、图片和文档时同时包含合法、超限和非法文件 | 查看上传结果 | 按项目资料专用类型/大小/数量校验；保留合法成功文件，逐个说明失败原因，非法文件不成立 | P0 |
| AC-M11-37 | 系统管理员维护采购包或平台公司 | 新增、编辑、停用或恢复配置 | 新增/编辑使用对应对象 Modal 且按钮为“取消 / 保存”；停用/恢复先显示对象对应确认弹窗和影响说明，按钮为“取消 / 确认”；取消、右上角`×`和点击遮罩均关闭 Modal 且不保存、不占号、不改变状态，确认后执行状态变更 | P0 |
| AC-M11-38 | 采购包已包含一个或多个课程方向 | 系统管理员新增、编辑或移除课程方向 | 允许维护多个方向但始终至少保留一个；移除使用`×`图标按钮并显示`移除该课程方向`Tooltip；已有项目继续使用其商业快照 | P0 |
| AC-M11-39 | 有权用户从项目列表创建项目，或从项目详情编辑尚未开始的项目 | 进入页面、取消、校验失败、创建成功或编辑保存成功 | 创建和编辑均使用独立页面，标题分别为`创建项目`、`编辑项目`；底部按钮分别为`取消 / 创建项目`、`取消 / 保存`；取消返回来源页且不保存或占号，校验失败停留当前页，创建成功直接进入项目详情且不显示成功 Toast，编辑保存成功返回项目详情并显示`保存成功` Toast | P0 |
| AC-M11-40 | 用户在项目创建或开始前编辑页触发必填、重名、负责人、时间、天数、资源组合、配置有效性、主讲师或排期校验 | 查看失败反馈 | 停留当前页面，在对应字段旁按 M11 4.4 的固定文案显示具体失败原因；排期冲突展示冲突讲师、冲突时间和关联项目编号；失败不保存项目、不生成或占用编号 | P0 |
| AC-M11-41 | PM 或区域总监名下存在未完成项目和项目并行待办 | HR/人事或 admin 尝试停用该员工，先后模拟未迁移与通过 M08 既有地区责任调整完成迁移 | 未迁移时阻止停用并提示先完成地区责任及适用项目负责人迁移；迁移全部成功且无未迁移未完成项目后才允许停用。项目记录、主阶段、并行待办和责任历史保留且不自动取消，停用账号立即失去访问与操作能力；不新增交接人字段、独立迁移审批或“负责人待分配”项目状态 | P0 |
| AC-M11-42 | 系统管理员新增或编辑平台公司，列表同时存在正常和停用记录 | 留空、填写非法/重复/合法统一社会信用代码，并组合平台公司编号、名称、统一社会信用代码和状态筛选 | 统一社会信用代码可留空；非空时必须符合 18 位格式且在全部正常和停用平台公司中唯一，非法或重复值不保存；名称按包含关系模糊匹配，编号、统一社会信用代码和状态精确匹配，多条件按 AND 取交集，输入条件不会自动改变结果，点击`筛选`后生效，点击`重置`清空全部条件并恢复默认列表 | P0 |
| AC-M11-43 | 创建项目、编辑未开始项目或进行中修改结束时间后，项目确认天数与系统计算天数不一致 | 提交创建或保存 | 先显示标题为`确认使用不同的项目天数`的弹窗，正文分两行显示`系统计算天数：X天；`和`项目确认天数：Y天；`，按钮为`返回修改 / 确认保存`；返回修改保留表单且不保存，确认保存才继续原流程；详情同时展示两个天数，列表只展示项目确认天数 | P0 |
| AC-M11-44 | 项目分别处于已立项、进行中、已交付、已完成和已取消 | 查看资料 Tab 并尝试新增、删除或替换资料 | 已立项和进行中只读且维护操作不显示、伪造操作不生效；已交付可按既有规则新增、删除和替换；已完成仅可新增非必填可选资料；已取消完全只读 | P0 |
| AC-M11-45 | 当前权限范围内存在不同创建时间的项目，且两个项目创建时间相同 | 首次进入项目列表或重置筛选 | 默认按创建时间倒序展示，最新创建的项目在前；创建时间相同时按项目编号倒序形成稳定顺序，筛选只缩小结果且不改变该默认顺序 | P1 |

> Source Governance（2026-08-31，DEC-188）：DEC-182 中“不以未交接项目阻断当前停用”的结论已被替代。当前有未完成项目时必须先通过 M08 既有地区责任调整完成适用项目负责人迁移；项目保留且不自动取消，不新增独立交接模块或迁移审批。
