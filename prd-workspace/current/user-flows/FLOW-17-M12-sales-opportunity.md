## 方案支撑

方案支撑仅在上述正常推进或详情允许阶段由有权商机负责人/admin发起；既有请求处理不受新发起阶段限制。商机负责人向一名或多名在职、账号有效且具有商机支撑角色的员工发起（可与 PM 等兼任），按员工 ID 去重；每次必须填写支撑需求和交付截止时间，每名支撑人员独立经历待响应、进行中、已交付、已关闭。被指派人从`方案支撑`处理本人请求，可进入被指派商机的精简只读背景页，无 Tab 或支撑请求表格，按 M12 §10“支撑视角商机详情”展示；列表与详情可接收当前明确的待响应请求，先按 M12 §10“接收二次确认”弹窗核对，最终确认才进入进行中；取消或关闭不流转，失效/重复确认不写入；详情接收后停留原页且按钮消失；文件提交返回方案支撑，无过程提交；最终填写文件说明并上传1-9个附件，全部成功后成为已交付，负责人按 M12 §10“方案验收二次确认”核对后最终确认关闭，取消不流转、失效/重复不写入；admin 从`方案支撑管理`查看公司全量并以真实身份代操作，但不作为候选或受理人。不判断或发送回应超时消息，不展示回应超时；每条请求通过“历程”查看本人的独立支撑流程，权限沿用原请求范围，交付截止不引入新的逾期自动处理。

支撑列表按 M12 §10“支撑列表剩余时间与筛选”展示实时剩余时间；待响应/进行中按截止时间升序，超时未交付优先，已交付/已关闭置后。用户先通过`全部`、`待响应`、`进行中`、`已交付`、`已关闭`五个状态 Tab 切换列表，再按商机名称、客户单位和交付截止日期范围组合筛选、重置；状态 Tab 与其他条件按 AND 组合，切换 Tab、筛选和重置返回第一页，详情返回保留当前 Tab 和已应用筛选。支撑接收、文件提交与权限沿用上述规则，不新增超时自动处理。

已交付内容不在支撑列表内铺开，通过操作栏“查看交付”打开最新交付的文件说明和附件列表，逐个查看或下载；补充中保留上次交付可查，新交付成功后整体更新，历次交付说明和附件在该请求“历程”中保留且可查看/下载。具体附件限制和失败原子性见 M12 §10“支撑文件”。

已交付 → 商机负责人点击“要求补充” → 弹窗填写必填“补充或修改说明” → 最终提交并复核 → 记录意见/操作人/时间、回到进行中 → 支撑人员在本人历程读取要求 → 重新提交说明与附件 → 已交付 → 负责人再次验收或要求补充 → 点击确认接收 → 二次确认弹窗核对商机与支撑人员/关闭后果 → 最终确认复核账号、权限、对象、指派、状态及本次交付 → 当前请求已关闭；取消不流转，失效/重复不写入。取消/空白/失权/重复提交不改变事实；原截止与历次成果保留，无新状态或消息。历程按记录时间倒序（最新在上，同时间按实际发生顺序倒序）独立展示每人的发起、接收、交付、补充、重新交付、关闭及附件，关闭保留来源上下文；完整交互及历史附件边界见 `prd-workspace/current/modules/M12-sales-opportunity.md` → §10“补充要求与支撑历程”、AC-M12-60/61/62。

## 失败保护

- 必填缺失、范围变化、关键人失效或非法阶段请求不改变当前事实。
- 并发阶段请求只有基于最新版本的合法请求生效。
- 指标校验、权限或并发失败不覆盖最近生效版本。
- 消息失败不回滚商机、跟进或支撑事实。
- 越权访问统一返回 403 且不泄露对象是否存在。

## 本轮生命周期、目标调整与纠错（2026-10-14）

- 正常推进由负责人手动判断，可跳过方案准备；进入中选/落选需材料及说明；错误事实由负责人在统一“推进阶段”选择回退／中选落选互转，提交原因及资料，按纠正结果重算业绩并保留历史；不允许同阶段日期金额修改或非法向前纠错。原主链只代表正常操作，落选不阻止纠错。准确入口见 M12 Owner §9及AC-M12-65/66。
- 公司已有年度目标调整 → 原设置入口填写新目标/原因并确认 → 本轮差额处理 → 市场副总或主管区域总监沿授权链路保存下级待生效调整 → 受影响链路全部守恒且零余额 → 总裁/admin完成 → 公司/下级整体生效；完成前统计读旧值。取消二次确认后全部未生效内容作废；同年下一轮只能在完成/取消后开始。初次分配与其他独立调整仍按§6.2，当前公司差额过程替代上方即时生效路径；准确入口 M12 §6.4及AC-M12-69/70/71。
- 支撑待响应可撤回；负责人/admin主动停止需原因及二次确认；落选关闭全部未关闭支撑，原因商机落选；关闭/撤回后如需新增请求。停用管理者指定有效接替人 → 确认前复核全部接替人 → 账号先停用 → 系统自动交接原请求且保留文件/状态/完整历程；缺接替阻止提交，后续交接失败账号仍停用、成功项保留、失败项继续处理。准确入口 M12 §10、M06“员工停用”及AC-M12-67/68。

## 交接异常与目标承接（2026-10-15）

- 移除支撑角色 → 复核全部未关闭请求与接替人及唯一性 → 原请求交接成功 → 撤销角色；失败全部保持。新增支撑也校验同商机同员工未关闭唯一性。
- 原负责人已失效/不匹配的落选恢复 → admin上传材料说明 → 匹配客户当前唯一有效PM/总监 → 同次恢复及责任记录；无匹配阻断。
