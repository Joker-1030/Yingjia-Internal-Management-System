```mermaid
flowchart TD
    A[打开登录页] --> B[输入手机号/密码/图片验证码]
    B --> C{验证码正确?}
    C -- 否 --> C1[保留手机号和掩码密码<br/>清空并刷新验证码<br/>通用错误且不泄露答案<br/>不计密码错误次数] --> B
    C -- 是 --> D{账号存在且可用?}
    D -- 否 --> D1[统一提示,不泄露账号是否存在] --> B
    D -- 是 --> E{密码正确?}
    E -- 否 --> F[保留手机号,清空密码<br/>刷新验证码并通用提示<br/>密码错误计数+1]
    F --> G{连续5次?}
    G -- 否 --> B
    G -- 是 --> H[锁定30分钟<br/>锁定期拒绝正确密码] --> B
    E -- 是 --> I[成功登录并使同验证码失效]
    I --> J{HR/人事?}
    J -- 是 --> K[进入M06组织与员工]
    J -- 否 --> L[进入角色默认有权页面]
```

HR/人事从任一无权页面执行返回时也进入 M06“组织与员工”，不回到无权的 M01 工作台。
