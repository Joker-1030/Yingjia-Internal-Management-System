## Quick Overview

- **谁使用：** admin 维护；总裁和市场副总只读；区域总监、PM、HR/人事无入口。

## 1. 模块目标

M09 集中维护影响客户档案、关键人任职、覆盖 KPI 和自动维系任务的基础配置，避免客户经营、维系管理、数据导入等消费模块分别维护一份配置。

本模块承担三个目标：

1. 维护一级至四级的常规维系周期、提醒、标题和执行要求，以及逾期后的升级消息阈值。
2. 作为行业、集团公司、客户公司、客户部门和标准关键人岗位的唯一人工维护入口，向其他模块提供同一组稳定客户主数据。
3. 维护预置生日/节假日任务规则及年度节假日日历同步结果，为下游任务生成提供确定的事件和规则。

配置变化只影响保存后新生成的对象。已生成任务继续使用生成时的规则版本快照，不因后续配置修改、停用或同步而被静默改写。

## 4. 页面与入口

入口名称为“客户基础配置”，仅对总裁、市场副总和 admin 可见。进入后固定显示三个一级页签，同一时点只展示当前页签：

1. 职级周期与提醒。
2. 客户组织树。
3. 生日/节假日规则。

页面首次加载超过统一阈值时显示 Loading；加载失败显示 Error 和重试。三个页签保留各自筛选、选中项和操作反馈，不把一个页签的业务状态复用到另一个页签。

### 页签一：职级周期与提醒

- 固定展示一级、二级、三级、四级四行，不分页。
- 列为职级、周期、提醒节点、标题模板、更新时间、操作。
- 每行拥有独立保存按钮；修改一行不改变其他职级。
- 页内另行展示“逾期升级提醒”，包括通知区域总监和通知市场副总两个阈值，并独立保存。
- 页面不展示配置版本字段；内部版本生成、并发校验、审计和任务规则快照继续生效。

### 页签二：客户组织树

```text
+---------------------------- 客户组织树 -----------------------------+
| 关键词  行业  集团  公司层级  节点类型  状态    查询 重置    ＋新增 |
+-----------------------------+---------------------------------------+
| 左侧客户组织树                     | 右侧选中节点详情                    |
| 行业/集团/公司子树/部门子树/岗位   | 主数据、完整路径、状态、审计、操作 |
+-----------------------------+---------------------------------------+
```

- 首次进入默认展开到行业层，不自动选中节点；右侧显示“请选择左侧节点查看详情”。
- 行业、集团、客户公司和客户部门可展开/收起。
- 每个父节点首次加载 50 个直接子节点，超过时显示“加载更多”；搜索结果不受已加载页限制。
- 搜索命中子节点时保留完整祖先路径；无结果显示“未找到符合条件的客户组织数据”，保留筛选条件并提供重置。
- 左侧树节点展示名称、类型和状态；行业可展示行业编码，公司展示公司层级。客户部门编码不在树节点展示。

#### 树结构与层级关系

树的固定对象顺序为：

```text
行业
└── 集团公司
    ├── 客户公司
    │   ├── 下级客户公司
    │   │   └── 客户部门
    │   │       ├── 下级客户部门
    │   │       └── 标准关键人岗位
    │   └── 客户部门
    │       ├── 下级客户部门
    │       └── 标准关键人岗位
    └── 其他客户公司
```

- 客户公司按责任省/市/区县自动形成省公司、市公司、区县公司子树，允许缺少中间公司对象，但不创建虚拟占位节点。
- 公司节点先展示直接下级公司，再展示本公司的直属客户部门。
- 客户部门必须且只能属于一个客户公司；下级部门与上级部门必须属于同一客户公司。
- 部门节点先展示直接下级部门，再展示标准关键人岗位。
- 标准岗位必须且只能属于一个客户部门；不存在部门直接挂集团、岗位直接挂公司或跨部门复用。

旧 PRD 附录 B / Shared 04 的“共享客户部门”已由 DEC-161/DEC-163 替代，见“Decision Governance”；旧文本只作 Historical / Replaced Evidence。

#### 新增入口与上下文联动

右上角“＋新增”仅 admin 可见，顺序固定为新增行业、集团、客户公司、部门、岗位。

| 新增项 | 最小上下文 | 从当前树节点进入时 | 上下文不足时 |
| --- | --- | --- | --- |
| 行业 | 无 | 不预填 | 直接打开表单 |
| 集团 | 行业 | 选中行业或其后代时预填行业 | 先选择行业 |
| 客户公司 | 集团 | 选中集团或其后代时预填集团 | 按行业 → 集团补选 |
| 客户部门 | 客户公司 | 选中公司、部门或岗位时预填当前公司；选中部门时可预填上级部门 | 按行业 → 集团 → 客户公司补选 |

任一上级变化时立即清空全部失效下级并提示“上级已变化，请重新选择后续信息”。提交期间禁用按钮；重复提交只产生一个对象并返回同一结果。

## 5. 用户操作

| 操作 | 执行角色 | 确认与生效 | 成功反馈 | 失败/阻断反馈 |
| --- | --- | --- | --- | --- |
| 保存职级规则 | admin | 保存前确认；仅当前职级立即形成内部新版本，只影响新任务 | “修改已保存”，显示更新时间，不显示版本字段 | 字段错误就地提示；版本冲突要求刷新；保存失败保留输入 |
| 保存升级提醒 | admin | 独立确认并保存；只影响后续阈值触发 | 提示保存成功 | 阈值非法或版本变化时阻止 |
| 搜索/筛选/展开树 | admin、总裁、市场副总 | 查询立即更新当前树结果，不改变对象 | 展示命中路径或子节点 | 无结果保留条件；加载失败可局部重试 |
| 新增主数据 | admin | 按上下文打开表单；保存成功立即生效，客户公司同步成为 M02 同一档案 | “{对象名称}已创建”，展示系统编号并选中新节点 | 上级失效、重复、责任无法解析或编号失败时不创建 |

| 停用/恢复 | admin | 行业/岗位按 M09 直接规则；集团/公司/部门按 M05/M04 | 显示最新状态；外部流程显示流程编号 | 影响摘要失败、下级/任职/任务/KPI 未处理时阻止 |
| 启停预置规则 | admin | 校验重叠后立即生效；只影响未生成任务和未发送提醒 | 显示最新启停状态 | 重叠、缺少节假日或非法字段时列出原因并阻止 |
| 同步节假日日历 | admin | 拉取并校验年度日历，成功后形成新可用版本 | 显示最近成功同步时间和版本 | 失败时使用最近成功版本并告警；没有可用版本时暂停相关调度 |

### 页签一保存与生效

admin 点击某行保存后显示确认弹窗：“确定修改？修改后已存在任务不受影响，新任务将按修改后的规则计算。”确认后只更新该职级并生成内部新配置版本。取消确认不保存；页面不展示配置版本字段。

逾期升级提醒使用独立保存按钮和相同确认语义。当前规则不提供“预览并重算”或批量重算入口；该结论与历史 Decision 的冲突见“Decision Governance”。

### 客户组织树停用与恢复边界

| 对象 | M09 入口 | 流程所有权 | 生效规则 |
| --- | --- | --- | --- |
| 行业 | admin 停用/恢复 | M09 | 直接生效；历史引用保留 |
| 集团公司 | 总裁、市场副总、区域总监、PM、admin 按真实对象范围发起；HR 不可 | M05/M04 | 按影响检查和审批结果生效；M09 普通配置写入仍仅 admin |
| 客户公司 | 总裁、市场副总、区域总监、PM、admin 按真实对象范围发起；HR 不可 | M05/M04 | 按影响检查和审批结果生效；M09 普通配置写入仍仅 admin |
| 客户部门 | 总裁、市场副总、区域总监、PM、admin 按真实对象范围发起；HR 不可 | M05/M04 | 适用未完成任务统一关闭；任职替代限同公司对象级规则，不产生通用任务转移 |
| 标准岗位 | admin 停用/恢复 | M09 | 引用数为 0 才可直接停用；历史引用保留 |

M09 不建立集团、公司、部门停用审批状态机，只展示当前对象状态、影响检查结果和外部流程编号。

## 6. 字段与业务规则

### 页签一：职级周期与提醒

#### 职级规则字段

| 字段 | 必填 | 默认/候选 | 只读与可见性 | 业务规则 |
| --- | --- | --- | --- | --- |
| 职级 | 是 | 一级、二级、三级、四级 | 全角色只读 | 固定且唯一，不允许新增、删除或改名；与客户公司层级解耦 |
| 常规维系周期 | 是 | 1-365 自然日；四级默认依次为 7/15/30/45 天 | admin 可编辑，只读角色只看 | 新任务的下一截止日按实际完成日期加当前周期计算 |
| 提前提醒节点 | 是 | 1/2/3/5/7/10/15/30 天前和截止日；默认 3、1、截止日 | admin 使用标签选择，只读角色只看 | 合法节点去重后倒序保存，最多 10 个；不手输数字串 |

### 规则状态

- 职级周期规则固定存在，不使用启用/停用状态。
- 逾期升级提醒本期只定义阈值编辑，未定义启用/停用状态。
- 生日/节假日预置规则使用启用、停用。
- 规则集合不使用草稿或发布状态。

### 操作结果

- 内部配置版本已更新：保存成功后的系统结果，不作为业务页面字段展示，也不是对象生命周期。
- 同步成功/同步失败：节假日日历同步结果；失败按是否有最近成功版本显示降级或暂停。
- 保存成功/保存失败：保留当前输入和上下文，不改变其他对象状态。
- 影响检查成功/失败：只决定本次停用是否可进入确认，不改变主对象状态。

### 错误与反馈

- **唯一性冲突**：行业、集团、公司、部门、岗位名称或信用代码冲突时指出冲突字段并阻止保存；无权用户不获得对象详情。
- **上级失效**：上级变化或失效时清空全部下级并要求重新选择；旧上级 ID 不能继续提交。
- **跨公司/跨部门**：客户部门不能选择其他公司部门为上级；岗位不能挂到其他部门；自身、后代和成环关系均阻止。
- **责任解析失败**：责任区划缺失、越级、停用或不能唯一解析区域/负责人时客户公司不成立，原数据不变。
- **版本冲突**：读取后对象已更新时显示“数据已被更新，请刷新后重试”和最新更新时间，不覆盖他人修改。
- **编号生成失败**：对象不成立、不显示成功；再次尝试不能产生重复对象或重复占号。
- **结果未知**：保存超时但结果未知时查询原操作结果；确认结果前不允许再次生成新编号。
- **同步失败降级**：有最近成功版本时继续使用并告警；无可用版本时暂停相关规则调度，不猜测日期。
- **保存失败**：保留用户输入、选择和当前页签，显示字段或全局错误并允许修正/重试。
- **影响检查失败**：只禁用本次停用提交，不影响主数据详情和普通编辑。
- **403 不泄露**：无权页面、对象、搜索、候选、唯一性检查和直接访问不返回名称、路径、数量或负责人。

## 8. 用户流程

本模块没有独立 Mermaid，保持机械迁移事实不变。M09 自有操作通过以下文字流程表达：

1. **职级/提醒保存**：编辑一行或一个阈值 → 校验 → 二次确认 → 保存当前项 → 生成内部新配置版本 → 后续新任务使用新规则；页面不展示版本字段。
2. **客户主数据新增**：选择树上下文 → 打开对应表单 → 补齐上级 → 校验层级、唯一性和责任 → 保存 → 选中新节点并显示结果。
3. **主数据编辑**：选择节点 → 编辑允许字段 → 校验版本与路径 → 保存 → 刷新详情和审计。
4. **预置规则启停/编辑**：打开规则 → 编辑允许字段 → 检查职级/节假日重叠 → 保存 → 只影响未生成任务。
5. **节假日日历同步**：触发同步 → 校验事件和版本 → 成功更新可用版本，或按最近成功版本降级并告警。

外部流程归属：

- 集团、客户公司、客户部门停用/恢复进入 M05，并由 M04 承载审批实例和节点；M09 不建立新的审批流程。
- 规则生成后的任务状态和完成认定属于 M03；M09 不拥有任务状态机。
- 逾期升级和同步异常消息进入 P01；M09 不拥有消息未读/已读状态。

## 9. 权限边界

### 产品事实所有权

#### M09 拥有

- 职级周期、常规提醒和逾期升级提醒配置。
- 行业、集团公司、客户公司、客户部门和标准关键人岗位主数据。
- 生日/节假日预置规则及其启停状态。
- M09 配置版本，以及任务生成时可供下游保存的规则事实。
- 年度节假日日历在 M09 的同步入口、当前可用版本和失败反馈。

#### M09 不拥有

- 客户浏览、关键人经营、任职和维系动作。
- 已生成任务、专项、覆盖 KPI 或维系记录的生命周期。
- 英嘉内部部门、员工、账号或系统角色关联。
- 区域中心、省份映射、地市负责人或客户负责人责任规则。
- 集团、客户公司和客户部门停用/恢复所使用的审批容器。
- 消息中心的未读/已读状态和跳转生命周期。
- 已生成任务的历史规则快照修改能力。

### 访问与字段边界

无权入口在导航中不可见。通过直接地址、搜索、唯一性校验、候选加载或其他方式访问时返回 403，不返回对象名称、路径、数量、负责人、重复对象详情或对象是否存在。只读角色的页面不显示写操作；伪造写操作同样返回 403。

配置版本作为内部并发、审计和任务快照事实保留，任何业务角色的 M09 页面都不展示配置版本字段。
