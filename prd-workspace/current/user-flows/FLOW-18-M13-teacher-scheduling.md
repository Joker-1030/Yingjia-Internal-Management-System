# FLOW-18 M13老师建档与排期

- 状态：CURRENT；Product Review：NOT REVIEWED；日期：2026-10-21。
- Owner：[`M13 培训老师管理`](../modules/M13-teacher-management.md) §3至9；关联 [`M11 项目管理`](../modules/M11-project-management.md) §9。

## 建档与维护

1. admin在M06关联老师/教学管理人员角色，在M13给管理人员分配内部/机构渠道/个人渠道范围。
2. 从“老师管理”菜单，admin/有权管理者新建档案，内部选择老师角色员工，外部填写公共资料和至少一个渠道；多机构共享同一档案排期。
3. 验证必填、所选采购包课程、联系格式和有权渠道；简历沿用通用附件规范，课酬带逐条税务口径。失败保留输入、整体不保存；成功刷新。
4. 详情按范围输出公共资料、联系方式及有权渠道/费用/简历；项目用户及老师本人不获得简历访问。取消/关闭不保存。
5. 修改方向前检查老师作为主/辅讲参与的已立项/进行中项目；移除其所用方向则阻止保存、保留原档案并提示受影响项目。项目负责人先按原阶段权限更换老师或调整项目，再由管理者重试；仅任助教不要求方向，不改写已交付历史。

## 项目选师

1. 在M11原有创建/编辑入口，采购包课程和平台师资合作培训项目均先选采购包、再选包内一门课程，填写开始/结束时间；老师教学方向多选同一来源的包内课程，不设独立方向目录或额外配置；原平台合作课酬保持。
2. 展示整段日期有空且适用方向匹配的启用老师；内部还须员工在职且有有效老师角色；主/辅讲匹配方向，助教不要求方向。
3. 保存再校验资格（含内部员工/角色有效性）、人工不可用、其他项目全天占用及原项目阶段权限，排除自身占用；失效员工不能通过旧表单被新选/替换加入。失败不改项目，保留选择并提示原因，无强制覆盖。
4. 保存后项目成为老师排期的只读来源；原项目取消、中止释放后续排期且保留历史。

## 不可用与停用

1. admin/有权管理者登记日期；内部老师只能维护本人登记的人工不可用。
2. 与已安排项目冲突则阻止并提示项目，项目负责人先调整；无冲突保存到统一排期。
3. 停用前检查全部未开始/进行中授课项目，有则须先换老师；已交付待资料/评价不阻断。
4. 确认停用只退出新选，保留历史及员工账号；恢复重新按方向和空闲参与候选，无自动改派或补造历史。
5. 若M06停用内部员工或移除老师角色，立即退出新选/替换，即使老师档案仍启用；已有项目、排期和历史保留，由项目负责人另行调整。员工停用时员工及账号按M06原规则立即失效，不等待换师；仅撤老师角色不因此停用整个账号，不自动修改老师档案状态或改派项目。

## 查看日历与甘特图

1. 从独立“老师排期”菜单进入视图，不与“老师管理”的档案列表混排；档案菜单沿原查看权限及对象范围，总裁单独增加排期只读入口。老师身份对应“我的排期”，纯老师登录默认进入，仍可从“我的信息”看本人档案；admin/教学管理人员使用“老师排期”，兼任沿有效角色和原落地优先规则。内部老师进入本人日历，默认北京时间当前月，只返回本人安排；可切月份，不提供他人筛选或单独老师角色的甘特图。
2. 总裁从“老师排期”进入，默认当前月/日历/全部内部与外部老师，可单多选或切月份、切甘特图，月份及筛选保留；仅查看原日程详情，不增加档案、联系、简历、渠道课酬或维护权限。兼任沿有效角色和原对象范围，总裁全体排期不扩大其他身份的档案/维护，原工作台落地保持。
3. 教学管理人员默认进入日历及当前月，展示全部负责老师；可筛选一名/多名，候选与日程均遵守原三项管理范围。
4. 查看当前月内的授课占用和人工不可用，跨多天连续展示，跨月安排展示与当前月重叠部分；占用口径和历史保留按原规则。
5. 管理人员或总裁切换甘特图，以老师为行、自然日期为列；共用当前月份及老师筛选，切换视图保留条件且不改变排期。
6. 点击日程只读查看既有安排及起止日期；项目详情仍按M11原权限，无权不能借日程跳转。不提供拖拽改期或项目人员修改，不扩大联系方式/简历/课酬权限；人工不可用仍从既有有权入口维护并校验冲突。
