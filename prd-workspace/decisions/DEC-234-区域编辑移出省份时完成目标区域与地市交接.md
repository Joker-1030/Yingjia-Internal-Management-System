# DEC-234 区域编辑移出省份时完成目标区域与地市交接

## 当前决定

1. admin 或市场副总编辑区域并移出一个或多个已关联省份时，先在同一编辑流程的“省份迁移与地市交接”弹窗中，为每个移出省份选择目标区域。
2. 移出省份已有 PM 负责地市时，需为每个已有地市选择目标区域内在职 PM；无已分配地市的省份不要求选择 PM。地市接收粒度和原子分组由 DEC-235 收敛。
3. 同一省份的已有地市按原 PM 与目标 PM 分组形成地市责任交接记录，按既有责任迁移规则同步迁移客户、关键人、未完成任务、适用项目和普通未落选商机；平台师资合作商机继续沿用生态独立责任，不随地区责任迁移。
4. 目标区域省份唯一性、目标 PM 资格、源/目标映射并发和全部业务迁移必须一次性校验；区域映射与交接任一步失败，全部保持原值，不显示部分成功。
5. 保存确认前展示逐省迁移摘要；保存成功提示为“区域配置及省份地市交接已保存”。

## 边界

- 不新增区域、地市、PM 或交接业务对象；复用 M08 既有区域映射、地市责任和责任变更记录。
- 不改变市场副总、admin、区域总监、PM 的既有入口权限；普通 PM 地市交接仍只能由原 PM 发起。
- 驻地城市与关联省份继续独立，编辑省份不自动清空或限制驻地。
