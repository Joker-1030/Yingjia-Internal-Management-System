# M12 Acceptance Criteria

> 当前角色/责任以 [`DEC-209`](../../decisions/DEC-209-PM统一承担销售与地市商机责任.md) → “决策”及 Owner PRD 为准；2026-09-08 已确认替代相关 AC 的独立销售角色/责任语义，稳定 ID、优先级和顺序不变，旧措辞可按 Git 历史追溯。


| AC 编号 | Given | When | Then | 优先级 |
| --- | --- | --- | --- | --- |
| AC-M12-01 | 用户进入当前系统 | 查看导航和 M12 页面 | 系统只有“销售与商机管理”入口，不出现独立“线索”菜单、对象、字段或转商机流程；早期机会直接以商机录入/需求确认阶段存在 | P0 |
| AC-M12-02 | 总裁、市场副总、区域总监、PM、HR 和系统管理员分别登录 | 查看仪表盘、商机列表并直接访问对象 | 总裁/市场副总/区域总监/PM 按公司/全国市场/主管区域并集/本人负责商机查看；系统管理员公司全局；HR 无销售入口且直接访问 403 | P0 |
| AC-M12-03 | 某月公司商机数量目标为 12，区域合计为 11 | 发布区域分配 | 系统指出月份和差额并禁止发布，不生成生效版本 | P0 |
| AC-M12-04 | 公司、区域和PM首次分配均守恒，随后市场副总和区域总监调整已发布目标 | 依次发布和调整 | 首次分配直接生效；市场副总调整区域目标、区域总监调整本人主管区域内PM目标时，在当前月/未来月、上下级守恒、原因和并发校验通过并二次确认后直接形成新生效版本；失败时原版本继续有效，不创建审批实例 | P0 |

> Sales target adjustment Current Rule（2026-09-04，DEC-204）：AC-M12-04 已移除当前审批语义；总裁、市场副总、区域总监和系统管理员仍只在原授权层级调整，业务范围、守恒、月份、原因、版本和历史规则不变。
| AC-M12-05 | PM 负责人在本月发生变更且存在历史月份目标 | 有权人员调整指标 | 只能另行调整当前月及未来月份；历史月份目标和事件归属不变，调整后继续满足上下级守恒 | P0 |
| AC-M12-06 | 当前存在跨周期商机及新建、中选、落选事件 | 切换年、季度和月 | 商机数量目标/完成及新建趋势按周期变化；全部商机、活跃商机、漏斗和覆盖保持当前快照并有明确区分 | P0 |
| AC-M12-07 | 当前有比选、中选和落选商机 | 查看仪表盘 | 活跃金额使用比选预估金额加中选预计签约金额；中选率只使用中选与落选结果；只有历史落选的客户不算当前覆盖 | P0 |
| AC-M12-08 | PM只负责济南销售范围 | 新建商机并打开客户和关键人候选 | 只出现PM 责任地市内有权正常客户，关键人只来自选中客户；客户集团、行业和业务责任事实只读派生，不在商机重复维护 | P0 |
| AC-M12-09 | 新建表单缺少首次跟进日期，随后补齐其他必填字段和有效日期 | 提交创建 | 首次提交不生成商机或支撑请求；补齐后只生成一个永久编号、创建时间、商机录入记录和当前跟进承诺 | P0 |
| AC-M12-10 | 商机处于需求确认 | 尝试跳到比选、退回商机录入，随后正常进入方案支撑 | 跳过和退回均被拒绝且无历史；正常下一阶段成功并保留不可覆盖的阶段记录 | P0 |
| AC-M12-11 | 商机处于比选或中选 | 分别缺少中选字段进入中选、由非负责人代推进、由负责人完整提交落选 | 缺少字段和非负责人请求被拒绝；完整落选进入终态并冻结停留时间；M12 不显示已签约入口或状态 | P0 |
| AC-M12-12 | 区域内有两名有效PM | 区域总监填写原因改派，随后尝试改派给区域外、无PM角色或停用员工 | 合法改派保留前后负责人和时间，历史事件归属不重写；非法候选不可选且直接请求被拒绝 | P0 |
| AC-M12-13 | 一条商机向两名员工发起方案支撑 | 两人分别响应、交付，其中一人超时，再由负责人确认或要求补充 | 两条请求按待响应、已响应、支撑中、已交付、已关闭独立流转和计时；超时消息发送给负责人和对应人员主管；补充及关闭历史保留 | P0 |
| AC-M12-14 | 员工仅因被指派方案支撑可见商机 | 查看详情并直接访问指标、其他商机或客户经营对象 | 只可见完成支撑所需的客户、需求和方案内容，不获得销售指标、其他商机或客户范围 | P0 |
| AC-M12-15 | 未落选商机的下次跟进日期为当天且之后连续 3 个自然日无新记录 | 运行提醒并在其后新增有效跟进 | 到期当日上午只提醒且不标记逾期，次日起才标记逾期并每日提醒，第 3 个逾期自然日同步区域总监；新跟进形成未来日期后旧提醒停止，节假日不顺延 | P0 |
| AC-M12-16 | 用户打开 M12 指标、列表、详情和操作区 | 查找合同、财务、回款、开票、成本、毛利和已签约能力 | 页面不存在上述维护入口、角色和状态；未接入事实不显示为 0；M11 当前人工创建项目入口和规则保持不变 | P0 |
| AC-M12-17 | 有权用户查看商机列表 | 查看商机编号、商机名称和操作列，并点击`详情` | 商机编号和商机名称以普通文本展示且不可点击；操作列显示`详情`按钮，点击后进入同一商机详情；数据范围、详情权限和返回列表行为不变 | P1 |
| AC-M12-18 | 当前月目标为 0 或 10，周期内有效新建商机为 0 或 12 | 查看目标卡片 | 目标为 0 时完成率显示`—`；目标为 10 且完成 12 时显示完成率`120.0%`、差额`+2`，正数明确表示超额 | P0 |
| AC-M12-19 | 用户首次进入销售仪表盘且存在跨年、季度和月事件 | 切换年、季度、月 | 默认当前月；年度和季度趋势按月，月度趋势按日，目标/完成/差额/完成率按所选周期重算，当前快照不随周期改变 | P0 |
| AC-M12-20 | 总裁/admin 已发布年度 12 个月公司目标但部分区域或PM尚未分配 | 各层级查看目标 | 已发布上级目标继续生效；未完成分配的对应层级显示`未分配`且不计算该层完成率，不用 0 伪装已分配 | P0 |
| AC-M12-21 | 员工具有 PM 角色且负责地市 | 查看权限、指标和候选 | 一套 PM 地市责任用于销售和原业务，PM 默认获得销售权限；目标与候选按稳定员工 ID 去重，不存在独立销售角色或责任 | P0 |
| AC-M12-22 | 区域总监或 admin 交接或直接调整某城市 PM 负责人且该城市同时有未落选与已落选商机 | 二次确认责任变更 | 全部未落选商机与 PM 地市责任同次原子迁移并记录改派历史，已落选商机保持原负责人；任一未落选商机迁移失败时整次责任变更不生效 | P0 |
| AC-M12-23 | 有权用户查看商机列表 | 检查金额、日期筛选、排序并制造同时间数据 | 金额列为`当前有效金额（含税，元）`；预计成交日期和创建日期均为包含起止当天的区间；按最近更新时间倒序，同时间按商机编号倒序 | P0 |
| AC-M12-24 | 当前负责人编辑未落选商机，随后商机进入中选 | 编辑允许字段、不可编辑字段和预估金额 | 落选前可编辑名称、优先级、预估金额、关键人、需求描述、预计成交日期；客户单位、商机类型不可编辑，负责人仅通过改派变化；中选后预估金额只读，每次成功编辑形成变更历史并更新最近更新时间 | P0 |
| AC-M12-25 | 商机创建、阶段推进、新增跟进、发起/更新支撑、改派或基本信息编辑成功 | 查看最近更新时间与排序 | 每个事件均更新最近更新时间并触发列表重新排序；失败提交不更新时间 | P0 |
| AC-M12-26 | 当前存在六个阶段的商机 | 查找停用商机、认定重复及相关筛选或指标排除 | 页面和接口均不提供这些未定义状态或操作；Current M12 仅使用商机录入、需求确认、方案支撑、比选、中选、落选 | P0 |
| AC-M12-27 | 发起人选择在职 PM、无 PM 角色员工及 admin | 打开方案支撑候选并提交 | 仅在职 PM 可选，按稳定员工 ID 去重；市场副总/区域总监仅兼任 PM 时可选，admin 不作为候选；未填写支撑需求时不创建请求 | P0 |
| AC-M12-28 | PM被指派方案支撑但没有其他 M12 权限 | 打开`我的方案支撑`并尝试访问其他内容 | 可查看和处理本人请求所需的商机编号/名称、客户、支撑需求、时限、状态和交付内容；不可访问销售指标、其他商机或 M02 客户经营 | P0 |
| AC-M12-29 | 有权用户查看销售仪表盘且商机列表已有筛选条件 | 点击指标卡、阶段漏斗或区域对比内容 | 仪表盘内容保持只读，不进入商机列表、不传递或改写筛选条件；八项指标的标签、数值和说明在桌面与窄屏均无重叠或溢出 | P1 |
| AC-M12-30 | 有权用户在新建商机时选择同时创建方案支撑，或从商机详情发起支撑 | 搜索、多选和移除支撑人员，并查看跟进记录与方案支撑 Tab | 两处候选范围和必填校验一致；全部已选人员在选择框下方展示且可逐项移除，不以`+N`省略；两个 Tab 内不重复同义标题或说明，既有操作和表格保留；首次回应超时作为独立事实显示且不改变待响应、已响应、支撑中、已交付、已关闭状态 | P1 |
| AC-M12-31 | PM、区域总监、总裁/市场副总和 admin 分别选择市/区县级或省级业务责任客户新建商机 | 查看负责人并尝试改写 | 市/区县客户自动匹配唯一有效地市 PM 负责人，省级客户自动匹配当前区域总监；负责人只读且不可由创建人改写，无唯一有效匹配时阻止创建 | P0 |
| AC-M12-32 | PM只负责一个或多个PM 地市，区域总监主管一个或多个区域 | 分别打开客户候选并提交越权客户 ID | PM只可选择本人PM 责任地市正常客户且负责人固定本人；区域总监只可选择本人主管区域省级业务责任正常客户且负责人固定本人；越权请求不返回对象信息且不创建商机 | P0 |
| AC-M12-33 | 所选客户存在多个当前有效关键人，且保存前一名关键人停用或调岗 | 搜索、多选、全部移除后提交，再重新选择并提交 | 已选关键人在选择框下方完整展示并可逐项移除；少于 1 人时不能保存；保存时按当前客户和有效性重校验，失效选择不写入，历史记录保留当时快照 | P0 |
| AC-M12-34 | 有权负责人新增跟进 | 查看并提交当前风险 | 只能从九项固定候选中单选；`暂无风险`互斥，选择`其他`必须填写说明；风险写入跟进记录但不新增商机状态或改变阶段 | P0 |
| AC-M12-35 | 员工负责 PM 地市或区域中心且有关联商机 | 员工停用并逐组交接 | 市/区县客户全部未落选商机随同一 PM 地市组交接；省级客户全部未落选商机随区域中心交接；已落选商机不迁移，不建立销售组，失败不回滚账号或成功组 | P0 |
| AC-M12-36 | PM 和 admin 分别进入销售指标或方案支撑 | 查看入口与数据并尝试越权 | PM 的我的销售指标只读展示本人月度数据和本人调整历史；admin 的方案支撑管理查看全量并保留真实身份代操作，不作为候选或受理人 | P0 |
