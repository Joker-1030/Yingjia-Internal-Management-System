# DEC-241 老师授课类型、分角色课酬与常驻地

## 当前规则

1. 内部/外部保留为老师来源。另维护授课类型，主讲、辅训、助教至少选择一项，支持多选；同人仍只有一份老师档案和统一排期，不按授课类型拆分身份。
2. M11原主讲师、辅讲师、项目助教三个槽位分别按主讲、辅训、助教筛选；原辅讲师统一称“辅训老师”，不新建第四个槽位。候选与保存都复核类型及原状态、内部员工资格、方向、整天排期。主讲/辅训仍要求匹配包内课程，助教不要求方向匹配。适用原创建与分阶段人员调整入口，不改变阶段权限、必填或评价范围。
3. 内部老师按主讲、辅训、助教分别维护对外标准课酬及内部结算课酬，最多六项独立参考价格。对外标准课酬供对外提供师资授课参考；内部结算课酬供公司向内部老师结算参考。本次仅维护档案价格，不增加实际结算流程。
4. 外部老师在个人及每家机构渠道内分别维护三种授课类型的参考课酬。各价格独立、可补录，元/天，非负、最多两位小数，金额与含税/不含税口径一起填写；未补录不等于零，不自动换算。填写价格不赋予未勾选的授课资格。
5. 沿用M13原费用与渠道权限，老师本人及仅有项目权限的用户不能查看这些价格。项目不读取或生成老师课酬快照，不增加成本、付款或毛利，不改变M11原报价、项目金额和平台合作课酬。
6. 老师常驻省份、城市必填，使用有效行政区划省市关系；不收集详细地址。常驻省市与授课类型属于公共教学资料，档案及项目选人可查看，不由常驻地增加地区限制、自动排序或自动派师。
7. 真实存量类型、驻地须由有权维护者核实补录，不凭姓名、方向、部门或历史身份猜测；信息不完整者不能新增或替换进入项目。已有项目、历史人员及评价不自动改派或重写，原报价保持。

8. 取消授课类型不以关联项目阻止保存，须弹窗说明并二次确认，列出当前全部已关联项目名称、当前阶段及当前负责PM（生态项目显示生态负责人）；没有关联项目也确认并显示空结果。所有已创建项目按原已选身份继续执行，编辑可保留；后续新项目及新增/替换身份按最新类型筛选复核，原方向/排期/员工资格与权限保持。取消/关闭/遮罩均不保存并保留表单；提交复核权限/版本及最新关联清单，清单或阶段/负责人变化需刷新并再次确认。确认后仅保存老师档案，不重写项目、评价、费用或历史。

## 决策来源与替代

2026-11-03用户要求：“老师的类型有主讲、辅训、助教，支持多选；项目选老师的选择要按老师的类型筛选拉取；内部老师的课酬有标准课酬（师资合作出去上课的），内部结算课酬，公司内部给老师结算的课酬；课酬还有辅训课酬，助教课酬；老师要有个常驻地的信息”。后续完整问答：

| 确认问题 | 用户回答 |
| --- | --- |
| 内部三种类型各有对外标准、内部结算两价格，外部每个个人/机构渠道分别有三种参考价？ | “是，三种类型分别定价，内部区分对外和内部结算” |
| 仅维护档案参考价还是增加老师实际结算？ | “只维护档案价格，暂不增加实际结算流程” |
| 常驻地按省＋市必填，并作为项目选人可查看的公共资料？ | “是，省＋市必填，选人时可查看” |
| 取消类型的最终处理 | 用户后续明确：“弹窗提醒，已经创建好的项目不变，依然按已选执行，后面的新项目按新的类型筛选，并且列出当前已经关联的项目名称和阶段已经负责的PM”；“不阻止保存，但要说明，并二次确认”。本最终决定替代此前同日的阻断方案。 |
