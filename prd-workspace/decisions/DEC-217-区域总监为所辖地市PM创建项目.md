# DEC-217：区域总监为所辖地市PM创建项目

- 日期：2026-10-09
- 状态：已确认；Product Status CURRENT；Product Review NOT REVIEWED。
- 背景：Product Owner要求“区域总监可以为pm创建项目”，原M11仅允许总监创建本人省级项目。

## 当前决定

1. 总监可为本人当前主管全部区域内市级/区县级客户的地市PM创建项目；保留本人省级项目创建。培训项目和AI软件项目均复用原创建入口、表单及校验。
2. 负责人继续由客户业务责任唯一决定，市级/区县级客户匹配当前有效地市PM，不提供任意选PM或跨区创建。无唯一有效负责人时，按DEC-175原规则拒绝立项。
3. 总监记录为真实创建操作人；项目创建负责人快照、当前负责人为匹配的PM。提交重新校验创建权限、当前主管区域和责任，不能使用旧表单资格绕过。
4. 成功后直接进入新项目详情；项目位于总监全部项目和PM本人项目，不因总监创建而进入总监我的项目。2026-11-10由DEC-246替代原“创建后总监只读”限制：按当前主管关系可代PM执行原阶段操作，资格不来自创建人；PM负责人及其维护能力保持。详见 [`DEC-246`](./DEC-246-区域总监代主管区域PM操作项目.md) →“当前规则”。
5. 沿用直接立项，不新增PM接收、项目审批或创建通知，不扩大M10导入范围或改变未来商机/合同接管边界。
