# DEC-255 生态项目恢复平台合作课酬计价

状态 CURRENT / NOT REVIEWED；日期2026-11-17；Owner M11 项目管理，关联M13 培训老师管理；CHANGE / MEDIUM；替代DEC-253生态消费及DEC-254生态消费例外，保留DEC-254老师档案税务三字段。

## 决策输入

Product Owner纠正：“生态员的项目是选平台公司，平台公司有合作课酬，按照那个价格和天数来算项目的金额，选择老师不要展示老师的金额，和其他项目正常选老师一致，现在的demo和需求偏了”。本轮明确撤销此前错误的老师报价消费分支，恢复平台课酬计价和原正常选师；不是继续按老师报价但隐藏价格。

补充输入：Product Owner明确“平台师资合作是不用选采购包和课程的”；并要求项目金额与商机成交金额、确认天数与系统计算天数不同时合并弹窗确认。

## 当前决定

完整计价、平台候选/商机、创建与编辑、快照及失败边界由 `prd-workspace/current/modules/M11-project-management.md` → §7.4“生态师资合作按平台合作课酬计价”维护；不选择或校验采购包和课程；选择平台客户后按该平台合作课酬（元/天）×确认天数自动计算只读项目金额。老师不参与计价，人员区不显示老师报价或合作渠道，不因缺老师报价阻止立项；撤销手改金额、老师报价参考、与老师参考价的差额确认及老师报价快照。项目金额与商机成交金额、确认天数与系统计算天数的差异按M11 §4.4统一二次确认。仍沿原培训阶段规则及平台商业快照，不批量改历史记录。

档案三字段及内部结算例外继续由 `prd-workspace/current/modules/M13-teacher-management.md` → §5“档案字段与建档”维护；生态不新增老师费用读取例外，项目选师边界见同文件§11.5“生态项目选师与报价权限边界”。验收 `prd-workspace/current/acceptance/M11.md` → AC-M11-ECOLOGY-PLATFORM-PAY-20261117；M13 → AC-M13-QUOTE-FIELDS-20261117 / AC-M13-QUOTE-TAX-20261117。既有Task/Result及发布证据保留，不回写历史。
