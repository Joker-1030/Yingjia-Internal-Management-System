## DEC-051：新增维系使用关键人稳定 ID 并展示客户单位（部分被 DEC-058 替代）

- 日期：2026-08-12
- 状态：部分被 DEC-058 替代
- 背景：全局新增维系表单自动选中首个关键人，且按姓名匹配记录和任务；同名关键人属于不同单位时存在错误关联风险。
- 决策：全局新增维系不默认选择关键人；候选使用关键人稳定 ID，并同时显示姓名和客户单位。选择后只读带出当前客户单位，记录保存、常规任务匹配和续期均以关键人 ID 为主键，并校验单位与执行 PM。上下文入口可锁定关键人，但同样展示单位。
- 未采用方案：继续按姓名匹配；只在候选文字中显示单位但提交仍使用姓名；默认选择列表第一项。
- 原因：防止误操作和同名错绑，使用户在提交前明确确认客户归属。
- 决策人：产品经理
- 影响范围：F006、F008、F010、CHG-076、CHG-078、CHG-089
