# DEC-230 商机跟进提醒与维系任务独立统一投影

## 当前决定

1. M03 维系记录与 M12 商机跟进记录是两个独立业务对象。维系记录可关联商机，但该关联不自动新增商机跟进，不改变商机阶段、负责人、销售业绩或 M03 任务完成/续期口径。
2. M12 商机跟进表单中的“下次跟进日期”继续作为当前商机跟进承诺。未落选商机的当前日期由 M01 工作台投影到商机负责人本人的“我的待办”：当天显示待跟进，早于今天显示已逾期；没有日期、已落选或负责人已无权查看的商机不进入。
3. 工作台提醒只提供查看商机详情的入口，不代替 M03 维系任务、不自动完成维系记录或任务，也不新增商机跟进。保存新的有效商机跟进后，旧日期提醒停止，由最新下次跟进日期形成当前提醒。
4. 工作台将该提醒在“我的待办”中单独归入“商机跟进”分类，不计入 M03 常规维系任务数量；维系任务仍按原规则强制生成和处理。其他待办分页、排序和权限规则保持；该展示归类不改变两类业务对象的独立性。

## 边界

- 提醒按 M12 当前负责人和商机查看权限实时计算；管理角色不因可查看全部商机而获得他人商机的“我的待办”。
- 到期/逾期判断沿用 M12：当天仅为到期提醒，次日起为逾期；消息中心既有到期/逾期规则继续由 M12/P01 维护。
- M01 只消费当前事实，不回放历史日期，不创建第二套任务或提醒对象。
