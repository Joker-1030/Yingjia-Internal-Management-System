## Quick Overview

- **模块解决什么：** 由唯一内置系统管理员维护角色模板权限、版本和审计。
- **谁使用：** 仅内置系统管理员 admin 可访问和操作。
- **主要页面：** 角色列表、四层权限树、权限详情、影响预览、版本历史和回滚。
- **关键操作：** 修改权限、保存、查看影响与历史、回滚。
- **最大边界：** M07 不维护员工角色关联、数据范围事实或业务模块固定权限上限。
- **未决治理：** DEC-085 的本人信息字段差异及其他未形成正式结论的来源冲突继续保留；M07 不裁决外部业务规则。

## 1. 模块目标

- 将高风险的角色模板权限维护收敛给唯一内置系统管理员 `admin`。
- 维护非管理员内置角色的菜单/页面、操作、字段和附件权限及其依赖。
- 在不改变数据范围派生事实的前提下，让管理员理解权限变更对角色和当前员工的影响。
- 通过不可覆盖的完整权限版本、影响预览、回滚和只追加审计，保留可追溯的权限变更记录。
- 使已确认的权限变更对新请求立即生效，并在用户失权时给出明确反馈。

## 2. 用户角色

| 主体 | 可见内容 | 可执行操作 | 不可执行 |
| --- | --- | --- | --- |
| 唯一内置系统管理员 `admin` | 角色模板、权限树、权限详情、影响信息、版本历史和审计 | 维护非管理员内置角色的四层权限，保存、查看影响、查看历史和回滚 | 不可修改系统管理员模板，不可新建/复制/删除/停用内置角色，不可修改数据范围计算事实 |
| 总裁、市场副总、区域总监、PM、HR/人事及其他非 admin 账号 | 不显示“权限授权”菜单，不返回角色模板和权限结构 | 无 | 不可通过直接访问、多角色并集或员工例外获得 M07 |

`admin` 的访问资格由不可变系统账号 ID 和内置管理员身份确定，不仅依赖可变登录名。权限授权自身不进入非管理员可编辑权限树。

| 对象/概念 | 产品含义 | M07 拥有性 |
| --- | --- | --- |

| 数据范围计算规则 | 角色用于计算可访问对象的结构化规则 | M07 只读展示；组织、区域和地市责任事实由 M06/M08 拥有 |
| 权限版本 | 每次保存或回滚后生成的不可覆盖完整权限集 | M07 拥有 |

## 4. 页面与入口

### 页面入口和布局

- 菜单名称固定为“权限授权”，入口为“系统管理 > 权限授权”。
- 页面以系统角色模板为对象，不提供员工授权页。
- 主页在最低 1366x768 下使用固定三栏：左侧“角色模板”、中部“权限树”、右侧“权限详情/影响信息”。
- 中部和右侧各自纵向滚动；底部保存操作栏固定且不遮挡末项。
- 版本历史是 M07 内的历史查看和回滚区域。当前 PRD 没有将它明确定义为独立路由，本 Candidate 不新增容器形态。

### 左侧：角色模板

- 固定展示角色名称、角色编码、在职员工数、数据范围类型、当前权限版本和更新时间。
- 支持按角色名称或编码搜索；输入 0-100 字并去除首尾空格。
- 内置角色按总裁、市场副总、区域总监、PM、HR/人事、系统管理员的固定顺序展示，不分页。
- 选择某个角色后，中部和右侧同步载入该模板的当前版本、权限树和影响信息。

### 中部：四层权限树

- 顶部展示当前角色、当前版本号和未保存变更数。
- 支持 0-100 字权限关键词搜索。搜索只过滤展示，不改变已选状态。
- 权限节点分为菜单/页面、操作、字段和附件四类，显示选中、半选、锁定和未上线状态。
- 支持展开/收起、勾选/取消和“撤销修改”。展开/收起只改变展示，不改变权限选中。

### 右侧：权限详情与影响信息

- 选中权限节点时，展示权限键、类型、依赖关系和锁定原因。
- 展示当前角色的数据范围类型、范围对象类型和计算来源，全部只读。
- 展示当前关联该角色的在职员工数，作为影响预览的基础信息。

### 弹窗和反馈容器

| 容器 | 用途 | 必须展示的反馈 |
| --- | --- | --- |
| 取消依赖确认 | 取消页面、查看或上传等前置权限 | 列出将被联动移除的子权限，允许取消或确认 |
| 保存影响预览 | 保存非管理员模板前二次确认 | 目标角色、基准版本、权限差异、在职员工数、可能失去当前页面的员工数和生效方式 |
| 回滚影响预览 | 对历史权限集发起回滚前二次确认 | 按当前员工重新计算的影响、当前版本、目标权限集、回滚原因和生效方式 |
| 未保存离开确认 | 切换角色、关闭页面或刷新前保护本地修改 | 选择离开则丢弃本地修改；选择继续编辑则保留当前角色和差异 |
| 冲突/失败反馈 | 展示版本冲突、依赖冲突、鉴权或服务失败 | 明确错误原因、可执行的刷新/修正/重试动作和请求编号；不显示部分成功 |

## 5. 用户操作

| 操作 | 可见/可用条件 | 用户操作 | 系统反馈 |
| --- | --- | --- | --- |
| 选择角色模板 | 仅 admin | 选择左侧角色 | 载入四层权限树、当前版本和影响信息；系统管理员模板全选只读 |
| 勾选/取消权限 | 仅 admin 编辑非管理员模板 | 修改四层权限 | 自动补齐依赖；取消前置权限时列出联动移除并二次确认 |
| 撤销修改 | 存在本地未保存变更时可用 | 点击“撤销修改” | 丢弃全部本地变更并恢复当前版本；无变更时禁用 |
| 保存修改 | 存在实际差异时可用 | 填写 5-500 字变更原因，查看影响并二次确认 | 生成新的不可覆盖完整版本并切换为当前版本；无实际差异不生成空版本 |
| 查看影响 | 保存或回滚前 | 查看权限差异和受影响员工 | 影响无法计算时不进入确认 |
| 查看版本历史 | 仅 admin | 查看版本记录或权限键级差异 | 按生效时间倒序展示，历史记录不可覆盖 |
| 回滚 | 至少存在一个历史权限集 | 选择历史权限集，填写 5-500 字回滚原因，重新预览并二次确认 | 生成新当前版本，不覆盖、删除或重新启用原历史版本号 |
| 搜索 | 仅 admin | 搜索角色或权限 | 只过滤展示，不改变权限状态 |

## 6. 字段与业务规则

### 角色模板字段

| 字段 | 展示/输入 | 必填 | 格式/默认 | 可见与业务规则 |
| --- | --- | --- | --- | --- |
| 角色 ID | 系统字段 | 是 | 稳定 UUID | 不展示完整值，不可修改 |
| 角色名称 | 只读文本 | 是 | 总裁/市场副总/区域总监/PM/HR/人事/系统管理员 | 内置固定，M07 不新增或改名 |
| 角色编码 | 只读文本 | 是 | `PRESIDENT`、`MARKET_VP`、`REGIONAL_DIRECTOR`、`PM`、`HR`、`ADMIN`；2-32 字 | 稳定且永久唯一 |
| 当前权限版本 | 只读文本 | 是 | `PERM-角色编码-六位流水` | 每次保存或回滚生成新版本 |
| 功能权限 | 树形复选 | 是 | 业务域 > 菜单 > 页面 > 操作 | 仅 admin 可编辑非管理员模板 |
| 字段权限 | 树形复选 | 是 | 对象 > 字段 > 查看/编辑/脱敏 | 编辑依赖查看；脱敏与明文查看互斥；不得突破业务隐私上限 |
| 附件权限 | 树形复选 | 是 | 对象 > 查看/上传/下载/删除 | 下载依赖查看；删除依赖查看和上传 |
| 数据范围类型 | 只读 | 是 | 公司全局/全国市场/所属区域/负责地市/公司组织 | 内置固定，不随四层权限保存而改变；HR/人事固定为公司组织 |
| 范围对象类型 | 只读 | 是 | 公司/区域/地市/组织 | 内置固定 |
| 计算来源 | 只读 | 是 | 公司组织/区域责任/地市负责人 | 结构化事实，不允许自由文本 |
| 模板状态 | 只读 | 是 | 启用 | 内置角色不得停用或删除 |
| 变更/回滚原因 | 多行输入 | 条件必填 | 5-500 字 | 保存或回滚时必填；显示实时字数，禁止纯空白 |

系统管理员模板始终四层全选且所有控件只读，不显示保存入口。admin 仅能修改总裁、市场副总、区域总监、PM 和 HR/人事模板的四层权限，不能修改角色基本字段、数据范围类型、范围对象类型或计算来源。

登录、退出、本人信息、本人修改密码和本人消息是系统固定基础能力，不进入可取消权限树。

### 权限节点与依赖规则

1. 权限节点使用全局唯一且稳定的权限键。展示名称变化不产生新键，已被版本引用的键不得复用表达其他含义。
2. 勾选父节点默认勾选全部未锁定子节点；取消父节点取消全部未锁定子节点；只有部分子节点选中时父节点显示半选。
3. 操作权限必须依赖所属页面访问和相关对象查看。勾选操作时自动补齐依赖；取消依赖时先列出将被移除的操作并二次确认。
4. 字段“编辑”必须包含字段“查看”。选择“脱敏”时取消同字段的明文查看和编辑。
5. 附件下载依赖附件查看；附件删除依赖附件查看和上传。
6. 系统必需权限显示锁定标识和不可取消原因。尚未启用的产品权限显示“未上线”并禁用，不得保存为有效权限。
7. 不满足依赖或包含不可授予 F002 的权限集合被拒绝，页面标记冲突权限并要求按最新权限树修正。
8. 权限搜索无结果时显示“未找到匹配权限”，不清除原有选中状态。

### 字段权限与固定业务上限

- 字段权限与字段固定隐私上限同时存在时，取更严格结果。
- 无字段查看权限时不返回字段；模板为脱敏时只展示脱敏值；模板为明文查看时仍不得突破业务字段固定上限。
- 字段编辑还必须同时满足明文查看、页面操作权限、对象数据范围和字段自身可编辑条件。
- 列表、搜索、候选、详情、导出、日志和直接访问使用同一最终字段结果。
- 员工手机号的当前固定隐私上限为所有角色统一脱敏。M07 不使用角色模板放宽该上限；角色模板只能进一步收紧字段查看结果。AC-F002-35 中即使模板配置明文查看也不能突破固定上限的结果与此一致。
- 关键人手机号在 M02 列表、详情、编辑、M04 审批快照和操作日志中同样对所有角色统一脱敏。该上限来自 DEC-163；M07 只能进一步收紧，不能通过明文权限节点放宽。

### 影响预览字段

保存或回滚前的影响预览至少展示：目标角色、基准版本、新增/移除权限、被移除菜单/操作、差异项数、当前在职员工数、可能立即失去当前页面的员工数和生效方式。

### 版本历史字段

版本历史按生效时间倒序，展示：版本号、状态、操作类型（保存/回滚）、操作人、操作时间、变更原因、权限增减数量、影响人数和权限键级差异。旧 PRD 没有枚举“状态”字段的候选值，本 Candidate 不自行新增枚举。

### 审计记录字段

每次查看版本详情、保存、回滚、失败保存和越权访问至少记录：事件类型、角色 ID/编码、基准版本、新版本、权限键增减差异、变更前后、影响人数、变更/回滚原因、admin 真实账号与姓名、来源 IP、请求 ID、结果、失败码、操作时间和生效时间。

审计记录只追加，不得修改或删除。M07 只允许 admin 查询，不提供删除或导出全部敏感权限结构的快捷入口。

## 7. 状态与反馈

### 页面状态

| 状态 | 用户看到什么 | 用户可以做什么 |
| --- | --- | --- |
| Loading | 当前角色、权限树、影响信息或版本历史的加载表达 | 等待加载完成；不在未完整数据上保存 |
| Empty | 角色或权限搜索无结果的明确文案 | 清空或修改搜索；原权限选中不被清除 |
| Error | 依赖冲突、版本冲突或权限服务不可用的明确反馈 | 修正、刷新或稍后重试；失败不产生部分结果 |
| PermissionDenied | 无入口；直接访问时显示 403/无权状态 | 返回已授权页面；不展示角色或权限结构 |

内置角色是系统必需事实，“全部角色模板不存在”不是普通业务空态，应按初始化或服务错误处理。

### 权限配置表达

| 表达 | 含义 | 允许操作 |
| --- | --- | --- |
| 当前版本 | 已加载的当前有效完整权限集 | 查看；非管理员模板可在此基础上修改 |
| 未保存变更 | 页面上存在未提交差异 | 继续编辑、撤销、填写原因或发起保存；离开前二次确认 |
| 影响待确认 | 已计算差异和影响，尚未生效 | 二次确认或取消 |
| 依赖待移除确认 | 取消前置权限会联动移除子权限 | 确认联动移除或取消 |
| 半选 | 父节点仅部分子权限选中 | 继续勾选或取消未锁定节点 |
| 锁定 | 系统必需权限不可取消 | 查看锁定原因 |
| 未上线 | 当前产品版本未启用该权限节点 | 只读，不得保存为有效权限 |
| 无实际差异 | 目标权限集与当前版本一致 | 保存按钮禁用，不生成空版本 |

### 版本关系和操作结果

- **当前版本**：对新请求正在生效的完整权限集。
- **历史版本**：曾经生效且不可覆盖的完整权限集。
- **已生效**：保存成功后的操作结果，不是独立发布状态。
- **回滚完成**：回滚成功并已生成新当前版本的操作结果。
- **版本冲突**：当前版本已被其他 admin 会话修改；不覆盖最新版本，保留本地差异供刷新后对比。
- **鉴权失败**：当前账号无 M07 或业务对象权限，显示 403 且不泄露对象信息。

当前 PRD 没有定义“草稿”或独立“已发布”状态，也没有独立发布操作。本 Candidate 不根据“当前版本/已生效”自行推导新的版本状态机。

### 错误与操作反馈

| 场景 | 反馈 | 结果保护 |
| --- | --- | --- |
| 权限依赖不合法 | `PERM-400-001`；标记冲突权限并要求按最新权限树修正 | 不保存不合法权限集 |
| 并发版本变化 | `VERSION-409-002`；展示最新版本号、操作人和时间摘要 | 不覆盖最新版本，保留本地差异，要求刷新后重新确认 |
| 保存或回滚失败 | 显示失败原因和请求编号，不显示成功 | 旧完整版本继续生效，不生成残缺版本或混合结果 |
| 权限版本或鉴权能力不可用 | `PERM-503-001`；显示请求编号并允许稍后重试 | 所有受保护请求失败关闭，不依赖旧导航或默认全权继续 |
| 无 M07 权限 | `AUTH-403-001`/403；不说明对象是否存在 | 不返回角色模板、权限树/键/数量、影响人数、版本或审计摘要 |

## 8. 用户流程

### 权限修改流程

1. admin 选择非管理员内置角色，查看当前版本、权限树和只读范围规则。
2. admin 修改四层权限，页面实时显示未保存变更数，并处理依赖补齐或联动移除。
3. admin 填写 5-500 字变更原因并点击“保存修改”。
4. 系统按最新当前版本重新计算差异和员工影响，展示影响预览。
5. admin 二次确认后，系统生成新完整版本并切换为当前版本。
6. 新请求立即使用新版本；导航最迟 5 分钟或在收到版本变化后刷新。
7. 用户因新版本失去当前页面时，当前页面停止后续请求、清理该页面的敏感缓存，并跳转到第一个有权页面。

M07 不定义草稿状态或独立发布操作。保存或回滚确认成功后直接形成新的当前有效版本。重复提交同一次变更不重复生成版本。

### 回滚流程

1. admin 查看版本历史并选择历史权限集。
2. 系统以当前版本和当前员工重新计算差异与影响。
3. admin 填写 5-500 字回滚原因并二次确认。
4. 回滚成功时生成新的当前版本，原当前版本和既有历史继续保留。

- 机械迁移的 [User Flow Index](../user-flows/index.md) 中没有 M07 独立 Mermaid 文件，本 Candidate 不新建业务流程。
- 旧 F002 和 AC 已确定的“角色选择 → 权限编辑 → 变更原因 → 影响预览 → 二次确认 → 新版本生效”和回滚流程已在本文用文字承载。

## 9. 权限边界

### M07 拥有的产品事实

- 非管理员内置角色模板的四层权限集。
- 权限树父子关系、前置依赖、锁定和未上线表达。
- 权限变更原因、影响预览、当前版本、版本历史、回滚和审计。
- admin 独占访问、系统管理员模板不可降权和非 admin 越权时的 403 不泄露边界。

### M07 消费的外部产品事实

- 员工与 1-5 个非管理员系统角色的关联由 M06 拥有。M07 只消费关联用于影响人数，不分配员工角色。
- 区域中心、区域主管和地市负责人等数据范围计算事实由 M06/M08 拥有。M07 仅只读展示计算规则。
- 各业务模块拥有其字段隐私上限、操作资格、对象状态和数据范围。M07 模板只能在这些上限内收紧或表达权限，不能放宽业务规则。
- 例如 HR/人事不能重置他人密码；仅 HR/admin 可在 M06 普通员工编辑中直接维护多部门关系和人工系统角色，并直接停用/恢复员工；区域身份只读派生；HR 受控查看初始密码的条件均不得因 M07 模板勾选而扩大。M07 可以收紧相应页面、操作或字段权限，但不能创造额外能力或改写自动角色来源。
