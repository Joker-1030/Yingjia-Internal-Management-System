## DEC-077：V2.0 新增独立合同管理业务域

- 日期：2026-08-14
- 状态：已确认，开放项已由 DEC-079、DEC-080 补充
- 背景：只在商机详情内保存签约字段无法承载合同资料、回款、成本、毛利、附件、版本和撤销审计，也不利于财务集中处理。
- 决策：V2.0 新增合同管理业务域，合同作为关联商机、客户、签约、回款、成本、毛利和撤销记录的独立可审计对象；合同与商机、客户均使用稳定 ID 双向下钻，不复制客户行业、区域或负责人文本。合同管理的菜单层级、一商机多合同关系、状态机、审批链、开票及履约范围继续由产品和业务确认。
- 未采用方案：继续把合同当作商机附件；在没有业务确认前直接套用完整项目或法务合同系统。
- 原因：合同需要独立的数据、权限和审计边界，但其生命周期会显著影响实现，必须先确认再细化。
- 决策人：产品经理
- 影响范围：F002、F006、F011、F013、F014、F016-F019、CHG-117、CHG-118、CHG-120、CHG-121
