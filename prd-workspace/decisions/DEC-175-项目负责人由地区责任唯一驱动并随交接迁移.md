# DEC-175：项目负责人由地区责任唯一驱动并随交接迁移

- 日期：2026-08-27
- 状态：已确认
- 背景：项目负责人若允许独立指定或出现空档，会与 M08 客户地区责任产生两套责任事实，并导致项目操作、提醒和资料维护失去唯一责任人。
- 决策：省级客户项目负责人为所属区域当前有效区域总监，市/区县客户项目负责人为所在地市当前有效 PM；无法匹配时任何角色包括 admin 均不得立项或导入。项目保存创建负责人快照和当前负责人，当前负责人始终随地区责任变化；PM/区域总监交接必须同步迁移全部已立项、进行中、已交付和已完成项目，已取消项目不迁移。地区责任与项目负责人同时生效，任一项目失败即阻断整个交接；不允许单项目脱离地区责任转交。
- 未采用方案：允许无负责人项目并标记待分配；admin 绕过负责人校验；项目负责人独立于地区责任手工更换；已完成项目永久保留原负责人。
- 原因：地区责任是客户和项目责任的唯一来源，统一交接可以防止责任空档并保留完整历史。
- 决策人：Product Owner
- 影响范围：M08、M11、M06、Acceptance、FLOW-16、Shared、Glossary、Product Boundary
