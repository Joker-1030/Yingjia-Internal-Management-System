## Current Product Flow

```mermaid
flowchart LR
    A[下载模板] --> B[上传文件]
    B --> C{单工作表业务行 <= 5,000?}
    C -- 否 --> D[批次级拒绝并明确提示]
    C -- 是 --> E[解析与预校验]
    E --> E1{客户行的显式组织上级和业务责任是否合法?}
    E1 -- 否 --> I[失败行保留错误结果]
    E1 -- 是或非客户行 --> F[确认可导入行]
    F --> G[每一业务行独立原子处理]
    G --> H[成功行生效]
    G --> I[失败行保留错误结果]
    H --> H1{适用当前 M03 规则?}
    H1 -- 是 --> H2[5分钟内幂等生成适用任务]
    H1 -- 否 --> J[生成批次结果报告]
    H2 --> H3{任务生成成功?}
    H3 -- 是 --> J
    H3 -- 否 --> H4[保留导入成功<br/>可幂等重试]
    H4 --> J
    I --> J
```

100 行允许形成 80 行成功、20 行失败；失败行不回滚其他成功行且不生成 M03 任务。一行内对应业务对象不得形成产品事实半成品。成功且适用 M03 规则的对象在 5 分钟内幂等生成任务；任务生成失败不回滚导入成功结果。

## 项目初始化导入分支

```mermaid
flowchart LR
    P1[初始化期下载项目模板] --> P2[上传项目基本信息]
    P2 --> P3[按最新客户业务责任匹配当前负责人]
    P3 --> P4{范围、负责人、名称和阶段校验通过?}
    P4 -- 否 --> P5[该行失败且不生成 XM 编号]
    P4 -- 是 --> P6[用户确认可导入行]
    P6 --> P7[每个项目行独立写入]
    P7 --> P7A[写入项目确认天数<br/>按开始结束时间生成系统计算天数]
    P7A --> P8[按原创建年份生成新 XM 编号]
    P7 --> P9[失败行不影响其他成功行]
    P8 --> P10[保留批次和结果报告]
    P9 --> P10
```

- admin 导入公司范围项目；区域总监只导入本人负责省级业务责任客户项目；PM 只导入本人负责市级/区县级业务责任客户项目。
- 项目模板输入`项目确认天数`，不输入系统计算天数；系统计算天数根据开始/结束时间自动计算并写入，培训项目金额和结账金额按项目确认天数计算。
- 项目导入只新增，不覆盖既有项目，不允许导入`已取消`项目；历史`已完成`但完成条件不齐时按`已交付`建立并展示缺项待办。
- 初始化完成后隐藏项目模板并拒绝新上传，历史批次和报告继续按权限保留。
- 区域总监导入本人负责省级业务责任客户关键人是独立且长期开放的分支，不随项目初始化导入关闭，也不扩大到市级/区县级业务责任客户关键人。

## Historical / Replaced Evidence

以下机械迁移块原样保留；“按工作表顺序原子写入”不得再解释为工作表整体原子。

```mermaid
flowchart LR
    A[下载模板] --> B[上传文件]
    B --> C[解析与预校验]
    C --> D{存在错误行?}
    D -- 是 --> E[查看错误明细/疑似重复<br/>修正后重新上传]
    E --> B
    D -- 否 --> F[确认导入]
    F --> G[按工作表顺序原子写入]
    G --> H[生成批次结果报告]
```
